## 用户指定的界面方向（2026-10-23）

界面采用苹果macOS应用的简洁分栏风格，取代旧深绿侧栏/苔绿主题。用户需要容易阅读、知道每项功能做什么、下一步怎么操作：每页用具体功能名、简短用途和操作顺序；高频操作可见，技术标识、用量、原始JSON和高级配置按需展开。审批对象、结果未知、停止未确认、删除索引限制等关键事实保留在操作附近，不能因简化而冒充成功。所有页面共享浅灰侧栏、白色内容、系统中文字体和蓝色主要动作；不增加假系统控件、外部字体或依赖。视觉规则以DESIGN.md为准，历史截图不代表当前外观已验收。

## 任务中心状态与追溯

任务详情增加“任务事件时间线”，只在用户点击后读取既有受授权事件接口，每次50条。本页保留最近200条已读取事件，较早项仅从页面收起；任务重查可从头读取。事件表仅含顺序/任务ID/类型/时间，不含日志正文。中文标签描述本地已记录事实，不替代当前执行、验证、记忆结论或原生实时状态；空页不承诺以后不会有新事件。整页身份/顺序/时间/游标一致才追加，错误保留已读取内容和原游标；任务/凭证变化或同任务重绘后旧面板响应失效。不自动轮询、重试执行或写浏览器存储。

接口提供outputValidation时，任务详情另显示“结果结构”：仅已声明且受支持的格式、服务端明确valid才显示符合结构，产物与测试结论继续独立。无效结果说明字段/大小/JSON问题及人工核对，不重编码或修改原结果。整段只是单一 Markdown 围栏且内部符合声明时，说明这是同一结果的围栏投影，并展示已投影字段；原文仍保留。未知schema不提交新执行/成功回传。未声明的内部历史记录显示无法确认，未结束任务显示尚未校验，旧接口缺字段不补造结果。没有手工篡改输出的按钮。

任务详情新增“产物与独立验收记录”原生折叠区，整理已有授权evidence，不发新请求。只展示唯一且与当前taskId/完整执行身份一致的正式verification记录：产物路径、期望/实际摘要与大小、读取上限，以及独立测试标识、退出码、输出截断和准确资源退出记录。历史验收与当前文件状态分开说明；没有正式验收回执不意味着产物不存在，模型output自述不作为证明。不显示命令、日志或宿主路径，不开放下载，不运行测试。每次最多20项，错身份/不支持格式提示核对原始证据，任务切换/退出清理沿用原详情。

列表和详情分别解释执行、验证和记忆状态：验证 `failed` 显示“验证失败”，记忆 `failed` 显示“记忆写回失败”，不改变原编码结论。两个领域使用各自已支持的状态集合，未知值保持未识别，不能借用执行成功的文案。

详情中的“流程与执行标识”折叠区展示接口已有的流程、发布版本、运行、节点、激活、attempt、原生执行任务与 Codex 会话/回合；返回角色版本时一并展示。缺失字段显示“尚无记录”，不从任务 ID 或配置推测。展开只改变本页显示，不拉取工具正文、不请求新执行、不创建角色或记忆。原始证据仍保留独立折叠入口，退出和迟到响应隔离沿用现有行为。

API返回 `executionObservation` 时，列表和详情另显示“最近核对”：unknown为“核对结果未知”，observed为“已取得原执行记录”。未知或无效字段提示保留已记录事实、查询原任务，不能据此重发。该字段不覆盖执行/验证/记忆结论；缺失时保留旧页面体验，不推测核对结果。更新时间只表示观察状态发生变化，不承诺实时在线。

任务详情的“已报告用量”仅展示API提供、原thread/turn一致的显式Codex响应记录计数。缓存/推理作为输入/输出子项，不能重复相加。父角色、完整任务总量、模型调用次数和费用保持未知；不把响应样本数当全部调用数，不把CLI token折算成实际账单。缺字段不显示新行，缺统计或格式不符明确未知，不影响既有执行/验收/记忆状态。

运行结果的“本运行已报告用量”只汇总授权原run下本地已登记任务，显示可测与缺失数量；不同节点、循环和重试按相同作用域纳入，不递归不同runId的恢复子运行或子流程。重复执行身份、矛盾证据或非法合计明确未知；无样本时不补零。页面交叉核对binding、run与可得目录身份，目录只留当前身份的project/workflow标识；这不是全调用树预算、父角色计量或实际账单。

## 记忆审核界面（已接入范围）

`memories.html` 延用 Operate 工作台视觉，用于已配置角色的任务来源记忆审核。独立审核凭证仅保留页面内存；显示真实角色、来源任务、审核记录与分页，支持核对正文后审核并写回。已有记录正文只读；提交未知时保留本页同一决定标识与正文，仅查询，不重发。退出清空界面并隔离迟到响应。

主路径为选择项目角色 → 选择已结束且资源已退出的任务 → 核对正文和来源 → 确认审核 → 查看官方写回读回结果。空页仍依据服务端游标允许翻页。此页不提供编辑既有记忆、自动生成正文、完整检索索引治理或召回成功保证；“已写回”不等于检索已更新。

受控删除复用既有后端：只有角色配置删除且当前独立身份具有delete_memory权限才开放首次请求，原正文摘要和来源身份须匹配。单独确认后只发一次固定决定，未知结果只查询原删除，不能重复POST。已有删除记录允许普通审核身份核对进度。分别显示文件/索引消失与角色阻断状态，当前原生索引无法确认清除时保持删除中并说明可能持续阻断该角色；不将文件消失或202称为完成。发起删除立即清除旧正文及技能候选，退出清除决定，非敏感防重标识仅在当前页面保留；既有审核和任务执行历史继续保留。源码接线不代表已经部署或执行删除。

历史任务入口：详情可携带项目、角色绑定和任务标识进入审核页；需重新认证与唯一授权匹配，不携带凭证或正文。来源核对后可整理元数据经验草稿，人工补全结论、适用/失效条件、版本和操作边界，再勾选审核提交；不复制模型输出、不自动写回或授予技能权限。新客户端提交来源证据摘要，冲突需重新读取核对。只完成源码接线，尚无本轮运行验收，详见 `../docs/task-experience.md`。

技能候选：只对已提交且未删除的人审经验开放独立折叠表单。用户填写名称、说明、版本、适用/失效条件、操作边界与步骤，经独立确认后导出完整JSON候选；原生创建请求显式要求禁用，不附脚本或配置，不在本页安装或启用。技能与普通记忆用途分开，步骤不由模型结果自动填入。原生状态核对只比较同一候选与固定角色下已安装文本/启用状态，不当作扫描或执行证明；未观察到不能认定名称可安全创建。凭证、草稿和候选状态不进入URL或浏览器存储，换任务/退出清除；下载文件由用户保管。实际交接仍待验收。

记忆审核首轮修正：来源任务选择后必须读取并匹配身份的正式结果/证据详情，预览截断明确提示；读取失败不开放新审核。退出清除审核正文与决定标识，仅留绑定/任务标识防重集合；换身份后只展示其授权 GET 返回内容。

写回恢复：已有审核处于 intent/pending/failed 时显示“核对写回”，通过受认证的原提交核对接口读取官方记忆。正文与决定保持不变，不重复 PUT、不启动编码；结果未知可再次核对。未发送的 approved、已提交、删除与冲突记录不开放此操作；退出清空与迟到响应隔离保持。

## 流程搭建页（本次增量）

`editor.html` 提供中文开始、条件、Agent 任务、有限循环、人工确认、结束六类节点的 SVG 画布与表单编辑。项目与流程列表、游标分页、创建、保存、发布及操作查询均使用独立凭证访问真实 authoring API；新空草稿的开始/结束初稿明确标为未保存。未知原生图保持只读。人工节点发布若缺审批绑定，展示服务端阻止原因；不提供运行按钮。

保存成功只在当前编辑仍与提交快照一致时更新 digest，不覆盖用户新内容。超时或不明回执保留项目/操作编号/类型，仅允许查询；退出与切项目清除凭证或草稿等敏感内容，非敏感防重标识保留在本页面内存。Agent 使用服务端配置的既有角色绑定；人工审批发布尚未接通；已发布流程可链接到运行页，由服务端核验准入。QwenPaw 原生角色与记忆不变，Sim 是草稿和发布的权威；浏览器不执行图、不保存长期记忆。

Agent 节点增量：从项目 roles API 读取既有绑定，不创建正式角色；配置任务模板、开始输入或前置 Agent 输出、原生记忆策略及明确失败分支策略。列表仅代表部署配置，不能视为原生角色实时健康。角色读取失败或绑定失效时禁止保存含 Agent 的图，保留旧标识，不按名称替换。输入来源须在所有路径必经；界面预检与后端校验共同保护。Agent 可保存/发布不代表完整执行已交付，执行仍需部署机器任务接口与可信角色。

Agent 节点可选择服务端声明且本地支持的结果格式：现有执行结果、编码结果或审查意见。旧角色接口缺少格式目录时仅回退到 task-result；未知、未声明或本地不支持的原格式保留标识并阻止应用与保存，角色、项目或凭证切换清除缓存。新编码/审查格式要求正文包含完整 JSON，条件可引用 `result.output.result.status` 或 `result.output.result.approved`。Agent 的 `approved` 是审查意见，不是人工审批，也不证明独立测试通过。默认新建节点仍选 task-result，读取既有节点时保留其原格式。

条件规则按数据来源提供原生字段建议：Agent 通用验收状态与文本、以及对应编码/审查 schema 的结果字段；结果汇合只建议通用验收状态，人工确认保留固定审批字段，开始输入仍由用户填写。字段路径仍可手动编辑；改变来源只更新建议，不替换已有路径。选择建议只填入当前表单，仍须应用节点配置并保存草稿。

发布回执提示：任务执行或结果回传尚未就绪、同一角色的记忆提交绑定缺失时，使用中文说明阻止原因并保留草稿；自动验收、角色和审批绑定的既有提示仍保留。阻止回执不会标成已发布或生成运行链接，不自动重投；本页可只查询原操作并保留原因。关闭页面后操作编号仍按既有约定丢失，新页面可重新读取已保存草稿。界面探针使用完全拦截的模拟回执，只证明静态界面行为，不代表真实 Sim 发布或后端准入已通过。

流程复制：在已保存、表单已应用、可编辑的流程下展开“复制为新草稿”，填写副本名称并创建。复用现有 create 接口建立独立空草稿，核对新身份和空图后载入源文档快照，明确显示尚未保存；用户点击原“保存草稿”才完成内容持久化。副本保留同项目角色绑定、节点关系、位置和记忆策略，不复制发布绑定、运行、Agent 或记忆。源流程及其版本保持。

创建回执未知时保留原操作身份与本页副本快照，只查询；查询后也不自动保存。目标已有内容或身份不符时不覆盖。退出、切项目清空副本正文，迟到响应无效；刷新后只恢复 Sim 已保存内容，未保存快照不持久化。

## 恢复执行查询

运行查询保留原运行状态，并独立展示服务端返回的恢复提交状态、恢复子运行标识与实际执行状态。较新提交为 intent/uncertain/unknown 时优先提示未知，旧恢复记录明确标为此前记录；失败不会被父运行的等待状态掩盖。页面只查询原标识，不自动重提、不增加重试按钮；执行状态不替代独立验收结论。无恢复字段保持既有查询体验，退出清空与迟到响应隔离不变。

历史运行目录按当前凭证可见的工作流绑定分页读取本地根提交账本，显示提交状态与更新时间，并明确不含原生执行状态。记录点击仅填入既有运行查询表单、清除旧结果和控制区；用户仍须手动查询原生运行，不自动启动、恢复或查询。项目/工作流身份、提交状态、更新时间、唯一运行标识及分页游标均在客户端核验；绑定、凭证、分页切换时隔离迟到响应。目录接口旧版返回404时说明目录不可用，手动运行查询继续可用。

## 接口兼容性提示

健康接口提供 `executionBlockReason` 时，原警告区显示服务端固定中文原因，停止新启动并保留历史查询。刷新、新触发标识和脚本表单提交不绕过该状态；退出清空，下一次连接重新读取实际健康。旧服务无此字段保持原体验，非法字段明确阻断。界面不控制 QwenPaw 的原生角色、会话或记忆，也不自动升级或重投任务。

## 有限循环编辑

循环节点仅配置既有 Agent 循环体和 1–3 次上限，最多一个循环，不支持嵌套。循环体必须显式开启允许失败分支、没有普通出线，输入来源为循环外必经节点；页面不自动修改角色策略。画布区分循环体/完成出口，失效循环体保留原 ID 并阻止保存。结果来源按循环先执行 body 再到完成出口计算，允许完成后的条件与结束节点引用 body 结果。原生固定校验 guard 由编译器生成，不作为可编辑代码暴露；执行与次数控制全部由 Sim 负责。

## 内置流程模板

目录中的“从模板创建草稿”源码已扩为20种场景，覆盖交付、修复、诊断、审查、升级、文档、迁移、发布准备等；说明区展示输入、产物和完成条件，角色必须从当前项目列表显式映射，团队的三个正式Agent必须不同。复用现有创建、操作查询、空图核对及主动保存流程；页面不创建正式角色、不自动发布或执行、不复制记忆。创建回执未知只查询原操作，保留同一未保存模板；退出、切项目清除名称、映射与正文。此前两模板的浏览器记录为拦截API加真实编译器；新增18项仅静态审查，未运行测试或实际创建流程，不能当作真实团队联调。

项目目录增加名称/描述搜索与原生运行次数、最近运行时间。提交才应用条件，翻页沿用已提交词；清除/切项目/退出重置。有界扫描的空页提示继续，未知运行信息不填零，旧后端无搜索回执时明确失败。

当前发布版本与草稿未发布修改由原生deployment状态提供；撤下后显示暂无当前发布版本，读取失败明确待核对，不从历史最大版本猜测。

画布支持节点拖动、缩放、全图适应和定位选中节点。拖动后仍需主动保存，Escape或系统取消撤销本次移动；未应用配置时先应用或放弃，再移动节点。缩放不修改流程。

原画布补充当前节点类型拖入、出口拖拽连线与自动布局。条件/循环沿用下方出口选择；键盘/触屏保留原按钮及连线表单。自动布局只改位置，未应用配置阻止布局，修改仍需主动保存；重复出口不创建多余连线。

归档入口要求已保存草稿且无待应用配置；确认后保留只读审计并从活动目录移除。归档记录可分页、读取完整定义/版本与可见运行证据、下载JSON；结果未知只核对原生归档范围，不重复归档。退出或切项目清空审计。

明确拒绝后的恢复：只有后端确认的 failed/official_write_rejected 且返回有效提交版本时显示“重试记忆写回”。以 expectedVersion 消费原版本的一次机会，保持审核人、决定与只读正文，不启动编码。未知、冲突或删除记录不提供重试；本页同版本的超时不重发，后续明确拒绝产生新版本后才可再次人工重试。界面76项fixture检查通过，不能据此认定真实宿主故障验收通过。

执行队列：任务列表与详情在registered时显示服务端声明的串行先进先出策略和等待原因，复用原文本行；只有查询结果，不开放插队或自动重发。等待准入检查不代表已就绪或已执行。字段缺失兼容旧服务，非法字段只提示暂时无法核对，不回显原始值；其他执行状态忽略迟到队列字段。暂停和角色版本诊断沿用原视图。

## Agent 团队

团队页读取当前项目的正式角色、组织关系和可用的活动任务摘要。关系由当前角色标识构成，最多 200 条；编辑时只选择现有角色，新增关系不能引用缺失角色，既有孤立关系可保留或移除。变更按团队 revision 显式保存并以原 operationId 只读核对。活动任务不可用或列表截断时明确告知；只显示任务/运行标识、固定中文状态和有限的原生身份标识，不显示输出或证据。此页编辑的是组织元数据，不创建角色、不启动工作流、不改变角色权限、Sim 流程、原生 Agent 或记忆。

## Agent 节点限额

Agent 节点可选自定义执行限额：单次实际提交意图时限为 1–86400 秒，同一运行同一节点的实际提交上限为 1–100 次；不勾选时不写入 `limits`，自动发现沿用 3600 秒/3 次默认值。次数覆盖同节点循环与重试，不是自动重试数；额度不足会阻止后续提交并需人工处理，未知受理不退款。旧角色接口未声明能力时不允许新增，已有 `limits` 原样保留并阻止该图应用、保存和发布，提示升级后台。

## 任务中心运行范围筛选

节点任务目录可按项目标识单独筛选；流程与运行标识必须同时填写且项目标识必填。范围标识最多256字符，提交前trim。编辑任一范围立即清空旧列表和分页，提示待应用并禁用翻页；应用、清除、刷新、状态或页长变化才读取。筛选响应必须回显精确filters，且整页任务身份均匹配所选项目/流程/运行；旧后端缺回显时说明不支持筛选，不冒充已筛选。未设范围时保留旧接口兼容。列表默认显示角色、项目、节点及状态，完整流程/运行/任务/节点激活/尝试标识按需展开，不读输出或证据正文。

运行详情只有在当前授权绑定目录提供项目和流程身份时，才允许手动进入该原运行的节点任务目录。入口守护原查询代数、当前表单值和绑定身份，使用原查询runId，不替换为恢复子运行；不自动查询、轮询或修改运行控制状态。筛选仅存在页面内存，退出清空，不写入URL或本地存储。每页完整核验身份后再显示，并核对页长与游标末项。
