# 简洁、易读的 macOS 风格工作台

模式为 Operate。2026-10-23用户明确要求苹果Mac应用风格，取代此前暖白/深墨/苔绿方案。产品仍为原生HTML/CSS/JavaScript网页，不伪装成桌面系统，不添加假窗口按钮，不改QwenPaw源码或认证、调度和记忆规则。

## 信息层级

每页使用具体功能名和一句用途，再说明操作顺序。标题27px、分区19px、内容14px、辅助说明13px；不使用编号眉题或营销口号。高频动作保持可见，首屏先回答“做什么、怎么开始”；完整ID、原始JSON、用量、版本和高级配置按需展开。执行、验收、记忆结论分开，错误和回执未知的处置说明靠近原动作，不因精简而隐藏。

首页：直接查看已有任务和已配置服务→筛选或刷新，无服务连接表单。运行管理 runs.html：操作授权→选择流程/填写输入→启动→查询结果。幂等触发标识在高级选项中，保留原默认生成/核对规则；表单无效字段若位于折叠区，原生校验时自动展开。任务中心默认显示项目、角色、节点与分离状态，完整任务/运行/激活/尝试标识在独立折叠区，点击任务仍打开原详情。按运行筛选也在明确命名的折叠区；从运行详情进入时展开并清除旧状态筛选，展示该运行全部状态。

QwenPaw插件入口默认直接打开同一总览，不再要求二次点击“打开中文工作台”，也不提供会回到空白入口的关闭按钮。任务与服务、原版画布可显式切换；切换或重新加载仍保护未保存内容。配置读取成功仅表示入口可用，不声称内嵌列表已经读取成功。

自然语言流程草稿复用模板库的已有角色选择与原运行入口。结果详情默认折叠，显式核对后显示规模与完整JSON，再勾选人工确认下载；导入、绑定角色、保存、发布仍分开。未部署服务端或能力未知明确禁用新配方，不新增模型配置、自动发布或另一个流程编辑器。

运行管理页的“系统能力与兼容状态”默认折叠，授权后显式读取；复用现有定义列表显示执行准入和模块配置。实际版本和观察时间另折叠，未知明确标注。模块配置不冒充健康或权限，不新增服务连接表单、设置框架或自动轮询。

任务详情：主要状态保持正文。执行标识、用量与执行设置、产物证据、事件、原始结果分别使用原生details；真实的停止未知/审批/写回失败提示保持可见。折叠不触发查询或动作，不使用CSS隐藏原生状态或删除业务证据。

任务详情的“主动核对原执行”复用中性次要按钮，旁边明确不会重新提交编码、可能同步原取消/超时/资源收尾。只有活动或资源未确认退出的任务显示，不自动查询；结果未知和核对成功不冒充执行或验收成功，切换记录后丢弃旧反馈。

产物下载沿用原证据折叠区，只对可核对的通过文件显示“核对并下载产物”次要按钮，旁边原位显示读取/拒绝/已发起下载说明。点击才读当前文件，不自动验收，不以单文件下载成功替代整体结论；不新增弹窗或装饰卡片。

流程搭建：选择或新建流程→编辑节点→保存草稿→发布。画布、所选节点、保存/发布及未知操作核对容易找到。复制、存档、专家数据和高级说明按需查看，原DOM ID、数据绑定和操作权限保持。

固定版本子流程入口默认折叠：读取流程→选择版本→选择连线和输入→预览→加入草稿。映射按需添加字段行，技术摘要按需展开。加入、保存、发布分别操作；固定内部节点只能调整位置，整体移除入口和原因说明放在同一区域。

人工审批：先选记录和核对内容，再批准或拒绝。业务验收与执行命令权限分区，保留提交未知和有效期等关键事实。记忆审核：选择已结束任务→核对正文→人工写入原角色记忆；删除和索引未清除说明保留。团队页：选项目→编辑已有角色关系→保存；不暗示角色关系会改变权限。

## 视觉与控件

220px浅灰侧栏，内容区白色表面与细分隔线，24–38px主边距。选中导航用淡蓝底和深蓝文字；主要动作实蓝，普通查询/返回用中性描边，危险操作使用可辨红色文字。页面主色由共享styles.css定义，局部页面不保留硬编码绿色主题。成功状态可使用明确语义绿色，不拿主题色推断执行已通过。

表单字体使用本机系统字体，macOS优先SF/PingFang，其他平台使用已有中文字体，不拉取外部字体。正文不使用等宽，JSON/代码与精确标识可使用等宽；长标识自然换行。控件桌面高度至少40px，移动端至少44px；焦点可见，不依赖颜色单独传达状态。选择色、光标和滚动条使用同一主题。没有装饰性动画或大量阴影。

## 响应式与可访问性

宽屏采用稳定侧栏与双栏工作区；1100px内收窄间距，740px内改为单栏与完整换行导航。任何导航项都不能仅因窄屏被隐藏。表单有标签，状态使用原有aria-live/status，细节用原生summary可键盘打开，取消/停止确认沿用原dialog。既有隐藏/禁用的认证状态、敏感内容清空和迟到响应隔离不变。

## 当前证据边界

本批只做源码静态审查，没有运行测试、Node脚本、浏览器、截图、HTTP/模型探针、lint或类型检查。旧桌面/窄屏截图及94/pass等历史视觉记录不能证明本次macOS外观已经通过。用户明确禁止继续测试，因此未执行技能的context脚本、概念抽签、检测器或visual-verdict；方向直接采用用户指定的macOS风格。

任务列表在分离状态下以次要文字显示登记时间、最近记录时间与中文事件摘要，沿用task-context，不增加指标卡或装饰。时间按浏览器时区；缺失显示尚无记录，不能将登记称开始或将最近事件称实时活动。开始时间只在响应已有 startedAt 时出现，沿用同一行样式，不另做指标卡。固定流程版本只在响应已有 workflow.revision 时出现，非法值显示尚无记录，不另做指标卡。负责人 Agent 只在响应已有 roleAgentId 时出现在任务行，非法值显示原记录未提供，不把角色绑定名称当成 Agent。

Agent自定义结果使用紧凑字段行（字段名、中文类型、必填、删除）及添加按钮；不用专家JSON承载高频编辑。仅选自定义格式时展开，切换提示应用后才改变草稿，保留未应用内容；用于条件的字段必须必填且为标量。

任务行的“等待原因”和“需要关注”放在原状态与时间附近，使用已有task-context自然换行，不新增指标卡或弹窗。有等待原因且文字相同时不重复“需要关注”。已返回的状态或队列才额外标阻塞类别：等待审批、等待回答、资源名额或占用、已结束任务的无效结果结构、提交或核对未知。没有对应字段时不显示类别，也不把暂停、准入关闭或角色版本问题说成认证失效。详情使用原正文行；原始资源、取消未知及独立结论继续保留。

节点角色摘要复用当前侧栏的文字行与原生details；主要用途、访问配置、原生记忆、验收方式可扫读，完整身份/执行缺项按需展开。只读值不伪装输入框，不添加健康徽章或新指标卡。

业务任务复用运行管理页目录：名称与目标可读，验收条目及标识按需展开；选用、关联运行是明确按钮。登记区默认折叠，登记与启动分别说明；运行回填不自动请求。业务目标与验收条件在授权任务列表和原任务详情显示；未授权首页仍只显示任务号。提交状态不冒充业务完成。

首页任务提供“查看任务详情”文字链接，点击区域至少44px；链接只传已有非敏感任务标识，运行页预填后仍需授权并点击查询。节点详情提供同次运行节点目录按钮，沿原筛选流返回，不添加新窗口或另一套任务列表。

授权任务详情的“负责人 Agent”取原登记身份，角色绑定等技术值放在原标识折叠区。负责人、原生执行任务与Codex会话/回合分别标注，缺失不推断；无额外卡片或配置读取。匿名首页不增加负责人私有字段。

业务任务条目的“查看节点任务”复用下方原任务中心，按项目与业务任务跨运行筛选；原范围折叠区增一个可选业务任务ID，不另建页面或重复节点列表。明确点击才读取，不改变启动目标；运行入口会清业务任务条件，避免旧条件隐藏同运行记录。

读取有效运行图后，在图上方用原定义列表显示已核对的项目和固定流程版本；操作者只说明提交回执没有该字段。任务参数是单独按钮，读取本地根提交输入，凭证和超限正文不展示，不另做指标卡。 节点任务行只在已有阻塞依据时增加一行原因，沿用任务中心文案，不另做指标卡。已授权时，节点上的“查看任务详情”查询原任务详情，复用角色会话、Codex 执行标识、产物、测试证据和记忆追踪入口；事件正文和记忆快照仍要在详情里再点一次。查看画布不加载历史工具正文，也不另建任务页。首页链接仍只预填。同一节点有不同尝试时，尝试标识直接显示；失败证据仍从该尝试进入原详情，不覆盖其他尝试。重新运行只走“以原输入准备新运行”，创建新运行记录，不原地重跑本次运行。

运行图置于原运行查询面板的默认折叠区，沿用浅色节点/细连线和中文状态。只读图与编辑画布分开，原尺寸优先可读，局部滚动、缩放与适合宽度；箭头仅表示定义，不用颜色伪造命中。键盘选择节点后列出独立三状态与所有已知激活/尝试，技术标识折叠；截断/未知/读取时间明确显示，退出或运行变化清理。

运行图自动更新是默认关闭的明确选项，只在已有核验图时读取本地状态摘要。 读取时间旁用一行文字说明运行图连接状态，成功和失败都不暗示 Codex 进程连接。成功时间、暂停和失败贴近刷新控件；隐藏页面/折叠/节点交互暂停，错误停止自动，不用旧计数冒充当前。保留选择、缩放、滚动与焦点，不增加另一组状态仪表盘。

“读取原生流程状态”是独立显式按钮，仅有效图后开放，不进入自动计时器。原生整体状态、整体流程是否暂停与本地资源分别成行、独立时间，摘要用分隔线而非嵌套卡片；标识折叠。是否暂停只复述已返回的原生状态，不另做指标卡。等待用途依据固定策略区分Agent结果/业务输入/定时/未知，不从human暂停推断用户必须审批，不把恢复点总数误写为待恢复数。Codex 活动保持未知，不从暂停或资源退出推断进程仍在运行。

运行管理的“已配置自动入口”默认折叠，复用简洁列表和标识详情。仅目录、原事件只读核对及回填查询，无创建/投递动作；未配置显示空态，不伪装活跃服务。

运行查询结果的运行额度用平面标题/定义列表展示已用、剩余、时限和观察时间；未知/未配置分别说明，不用进度条将未知伪装为零，不增执行动作。切换身份或运行即清旧摘要。

流程搭建页“JSON模板”默认折叠。导出先只读预览并核对用户内容；导入先显示本地摘要和显式角色映射，再校验载入画布，保存与发布仍独立。换图/身份/角色使临时文件和迟到响应失效，不引入新主题或模板状态库。

运行结果的“本地运行检查”默认折叠，各待处理计数分领域，不用绿色健康标识暗示原生活动；五分钟无本地事件只是说明窗口。独立“只查本地记录”读取本地原账本，在Sim断连时也可用，切换查询清旧控制和运行图，不触发执行。

任务详情的原生记忆/委派追踪默认折叠、手动读取缓存，只显示工具事实及按需展开指纹，不展示记忆正文；顺序与注入核实分开。抓取时间缺失不以读取时间替代，换任务/身份清旧，无自动读取或新动作权限。

召回证据核对位于已有快照下的默认折叠区，只有明确输入非敏感预期文本后才查询；统计字面结果命中与关联指令命中，语义相关性和实际Codex注入继续显示未核实。输入变动或快照重读使旧回执失效，不保存输入、不增加自动检索、评分图表或另一套记忆控制台。

项目目录下静态批量配方默认折叠，普通模式每行一项，高级模式JSON；角色/共享说明/完成条件明确选择。预校验后按原流程创建草稿，手动保存/发布/启动；同角色可能串行，不将配方称为动态批量引擎，失败和未知创建不自动重投。

批量项：节点配置与任务详情以默认折叠区域展示项序号、稳定标识、输入指纹及本项数据。编辑器批量数据只读，普通角色/指令编辑保留冻结数据；匿名任务服务总览不新增输入字段。

任务详情的“用量与执行设置”可展示当前项目执行容量（上限/占用/剩余）；无法核对明确待核对，达到上限由既有关注事项解释排队原因。不是流程运行数，原角色与工作区限制继续生效。

记忆批量审核：在原来源/正文编辑区提供“加入批量待审”，同项目最多10项；队列默认折叠，完整正文逐项展开，再勾选总确认按顺序写回。暂存不写回，不把失败/未知当成功；已发项只查询原记录，前项未committed时停止后续。切身份清空正文，原单项提交与队列共享本页防重。

候选写入期限在记忆正文下默认折叠，使用本机时区日期输入，明确应用后才写入正文首行UTC并取消原同意勾选。期限状态贴近正文；过期候选不能首次写入或明确失败后重试，已有提交仍可核对/删除。说明已写入内容不会自动失效或退出原生召回，不把写入期限当作新记忆引擎。切来源清除未应用时间，服务未声明保护时禁用设置和带期限候选提交。

发布历史：流程下默认折叠，显式分页读取，选中项只读对应revision/deployment/规范图摘要、节点连线与读取时本页草稿差异。不会覆盖或恢复草稿，不提供运行历史部署；JSON默认折叠且脱敏显示。切项目/流程/身份清历史及迟到响应，不自动查询。

流程目录的本地提交摘要复用原workflow-summary文字行，单独标注全部版本本地提交数量及最近登记状态/记录更新时间；原生运行次数保持原字段口径。不新增卡片、自动查询或执行按钮，未知显示待核对，受理不等于执行成功。

任务详情的“查看此节点的全部激活与尝试”复用原任务中心，清状态/业务任务筛选；节点标识在原高级范围区。按同次运行节点查找不新建尝试，完整激活/attempt标识仍按需展开，任务ID顺序不称时间线。

条件数字比较值超出安全范围时，在原应用/保存提示中说明大整数编号应改用文本；不自动舍入、变换字段类型或增加弹窗。原节点表单和画布布局保持。

嵌套结果fields-result-v2独立命名“嵌套结构（高级JSON）”，仅复杂对象/数组使用默认折叠定义区；普通字段行继续v1。提供analysis.status路径示例，字段建议只列逐层必填标量；修改后仍明确应用/保存/发布。格式切换保护未应用文本，错误沿原提示，不增加弹窗或指标卡。
