# Sim 原数据启动保护

本轮补 PRD AC-29 的 Sim 切片，保持 QwenPaw 主程序、原生角色/ReMe、现有适配服务与上游源码。代码只增加原数据库入口的检查，完善现有显式初始化与健康脚本，不增加常驻服务、安装身份清单或状态机。

普通数据库启动先检查原集群关键文件/目录，再交给官方 entrypoint；空目录不能自动执行 initdb。首次初始化只能从现有 `run.sh init` 显式执行，使用原 `db` 服务的临时实例，核对正式 PostgreSQL 进程就绪后停止并确认移除。目录锁阻止初始化期间普通启动；即使初始化进程消失，遗留 oneoff 或查询未知也会阻止启动。初始化失败保留现场，不重新提交或清空目录。

健康脚本另做零行 UPDATE/回滚。真实隔离数据库设为只读时，`pg_isready` 仍成功，而此检查正确失败；恢复后原行哈希不变。该检查不证明磁盘持久可写，不放到迁移前的 PostgreSQL healthcheck 中，以免等待尚未创建的业务表。
