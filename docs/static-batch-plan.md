# 静态数据批量流程配方

继续PRD7.6/R17数据项、逐项身份、输出映射和显式失败策略。复用已有Sim静态并行/Agent/汇合图、原角色和任务账本，不增加批量调度器或第二套状态。第一阶段静态2–20项；动态运行时列表和嵌套/单项模式仍未实现，不将本功能标成整个R17完成。

- 原项目编辑授权本地preview：严格JSON/规模/角色/策略检查，构造确定性节点ID与每项数据摘要，数据作为本项冻结任务指令内明确引用JSON；公共运行输入仍独立。只compile校验，无HTTP/持久写/Agent创建。
- 同一正式角色复用各项，各项独立节点激活/任务/attempt；原角色/工作区租约可串行，Sim图并发上界为项数，不宣称实际并行编码。all_success/allow_partial明确选择，后者仍需至少一项独立验收通过；失败结果只供汇合，不自动重试。
- 编辑器默认折叠“从数据清单创建批量流程”：普通每行一项，JSON数组高级模式；共享指令/既有角色/策略/名称。预校验成功后复用原create→确认空白→本地载入，手动保存/发布。未知创建保留原operation/copy，不重投；换身份/项目清私有表单/迟到。
- 原native-role与验收策略保留，用户数据可能含秘密不自动脱敏。root前端，Luna后端，Luna静态复核；无测试/Node/HTTP/浏览器/模型/lint/build。原维护重载保留数据，AC不提升。
