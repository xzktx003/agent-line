# 原生记忆写回回执丢失后的核对

QwenPaw 继续管理原生记忆正文与检索。扩展复用既有提交账本，增加一个只读核对入口和页面按钮，解决正文已写入、确认回执丢失后只能停留在 pending 的问题。没有增加记忆引擎、数据库结构、运行依赖或常驻服务。

## 用户操作

在“记忆审核”选择已有审核记录。写回状态为“等待核对”时，点击“核对写回”。服务用原角色、任务、审核决定和正文摘要读取官方原文件；一致时更新为“已写回并读回核对”，内容不一致时要求人工核对，读回不明时继续等待。正文保持只读，页面不要求再次审核或重新编码。操作中禁用重复点击，退出清除凭证与正文。

接口为 `POST /extension/v1/memories/{binding}/{task}/reconcile`，请求体严格为 `{}`，200 响应与记忆详情相同；应读取 status 判断结果。身份、范围、维护及原审核完整性检查沿用现有服务。仅 intent/pending 可读回核对；approved 不首次 PUT，删除及冲突状态不重新提交。即使原提交后又补充独立测试证据，也保留原审核的来源快照。
