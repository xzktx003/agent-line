# 同节点尝试目录计划

复用原授权node-tasks目录与TaskStore分页，增加可选nodeId，必须同时提供完整项目/流程/运行，匹配冻结payload.workflow.nodeId。该目录包含同次运行同逻辑节点全部激活与尝试，不跨运行拼接；不把分页的任务ID排序当时间顺序。原业务任务筛选可叠加，游标必须在完整节点范围内，匿名首页不变。

原任务详情增加明确按钮，清旧状态/业务任务条件、设置节点范围，沿原任务中心查询。范围输入、退出、清除、运行入口和业务任务入口均处理新字段；整页先核回显及每项身份，旧服务不支持时拒绝把宽范围当节点结果。保留真实activation/attempt，不猜测缺失值，不创建新尝试、执行或原生请求。

只读源码/AST与Luna审查，不新增/执行测试、HTTP、浏览器、Node、模型或构建。后端普通维护重载只按既有空闲/备份/归属/摘要规则进行，验收矩阵不提升。
