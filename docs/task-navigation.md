# 任务中心追踪入口

首页“已有任务”每条记录有“查看任务详情”。打开同源运行页后，任务标识已填入；使用原运行凭证授权，再点击“查询任务”读取详情。不需要复制长任务ID，不会把凭证、目标正文或证据放入链接。

节点详情可点击“查看同次运行的其他节点”，按该记录的项目、流程、运行身份读取原任务目录；清除上次的执行状态筛选，以便看到该运行的不同节点和重试。运行图节点上的“查看任务详情”在已授权后查询原任务详情，打开已有的角色会话说明、Codex 执行标识、产物、测试证据和记忆追踪入口。事件正文和记忆快照仍需在该详情里再次点击才读取。画布不加载历史工具正文，也不另建任务页。首页链接仍只预填。原查询身份和绑定一致性检查保持不变。任务、激活、尝试、Agent与Codex身份继续取原接口记录，不从标题推断。

链接使用fragment中的单一、受限task标识；初次加载或hashchange仅预填并清理旧详情/取消目标，使此前任务查询的迟到回执失效。链接不认证、不查询私有记录、不启动或取消任务。手动查询仍经过原Bearer、项目范围和任务响应ID检查；同运行跳转只有用户点击才读取目录，失效详情的按钮不再生效。

只修改仓库内原生静态前端，现有StaticFiles直接读取这些文件，无构建、后端重启、数据库写入或上游改动。仅源码静态复核，未运行测试、Node、浏览器、HTTP、lint或构建；不能据此声称视觉/交互或完整PRD验收通过。
