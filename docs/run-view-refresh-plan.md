# 运行图本地状态自动更新

继续PRD13.4最后更新时间/连接状态与必要摘要读取。复用现有固定图和任务库，图初次核对后只刷新必要任务状态，不反复读取原生发布版本，不增加执行调度或模型请求。

- 将run_view原pin/根记录核验与任务白名单投影提取为共用函数，保持固定版本/图摘要核对。新增受原授权state GET，调用方必须带已有图摘要；服务端重新核原历史pin与根记录、项目/版本和本地任务，只返回身份/状态/覆盖/读取时间，不返回图正文或发原生请求。
- 本地任务只能归属冻结agentPolicies的节点，并与图节点（初次读取）和发布修订一致；旧记录不合要求保持拒绝，不改变执行行为。
- 前端默认不自动更新。用户读到有效图并勾选自动更新后，每次完成再等待10秒；失败停止、退出/身份变化清理，页面隐藏/折叠/图交互时暂停，不重叠轮询。不因恢复显示自动重新读原生图。
- 每次状态身份及摘要必须等于已验证缓存，再复用原整页校验；保留选择/缩放/滚动。错误明确最后成功快照已过时，不把旧计数伪装当前；原生节点/连线命中仍unknown。
- 根backend与Luna独立frontend，源码/AST与Luna复核；无新增/执行测试、Node、HTTP、浏览器、模型/探针、lint或构建。仅原维护保护/空闲/备份/优雅重载核对，原生QwenPaw/记忆/上游不改。
