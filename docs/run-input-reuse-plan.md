# 从原输入准备新运行

对照PRD11.2“查看、复制为新运行”，补现有运行查询缺失的输入复用。复用原Sim提交账本，只读读取当前授权绑定和原发布范围内的根输入，不查询Sim、恢复或重投旧任务。限制64,000字节，返回固定身份、来源与规范输入hash；不返回触发键、回执、审批或其他项目数据。

前端默认折叠，用户显式读取预览，确认覆盖启动表单后才填入当前绑定与输入，并生成全新触发标识、清除旧业务任务关联。启动仍须单独点击且走现有发布/就绪/预算/身份检查；旧运行保持，不称为重试或恢复。切身份、绑定、运行及启动表单变动时使旧读取失效，不持久化输入、不增加调度器或新服务。

改动局限原journal/workflows接口和工作台，源码/AST与指定Luna审阅，不运行测试/Node/HTTP/浏览器/模型/lint/build。已有未知提交不能因复制表单而视为未受理；新运行明确可能再次产生业务副作用，需要用户在启动前核对。
