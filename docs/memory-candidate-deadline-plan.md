# 记忆候选写入期限

在已有审核正文中提供可选首行“候选写入截止（UTC）：YYYY-MM-DDTHH:MM:SSZ”，由用户明确设置并随正文哈希冻结。不新增数据库、后台调度或原生记忆引擎。新审核登记、首次write intent和明确拒绝后的retry intent拒绝过期或格式损坏；intent/pending核对及历史GET、删除保持可用。

前端可选时间仅编辑本页未提交正文，单项与批量提交共用服务端保护，批量实际发送前再次检查期限。不把期限称为原生召回失效：已写入内容到期后仍可能被原生检索，界面与文档明确这一限制。

只阅读源码和标准库AST，指定Luna独立静态审阅，不运行测试/Node/HTTP/浏览器/模型/lint/build。必要时沿原维护保护空闲重载，不改QwenPaw、角色、正式预算或系统配置。
