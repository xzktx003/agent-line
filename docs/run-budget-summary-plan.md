# 运行级额度摘要实施

补PRD的预算面板与AC66可观察性，复用已有运行冻结快照和TaskStore额度账本，不改准入/退款/取消规则，不创建表/依赖/调度器或修改正式预算。

- TaskStore只读scope摘要：与已冻结runBudget交叉核对，先登记尚无节点也可显示原策略；旧运行无快照且无任务则unknown。有任务但声明冲突/历史损坏则unknown，不能显示0。
- 原授权运行查询附加bindingId及固定scope、configured/not_configured/unknown、次数/剩余/时限/截止、仅预算准入判断和观察时间。未配置不冒称无限可执行，未知用量不变。
- 简洁运行额度面板，完整身份与数值校验，作用域切换/退出清旧结果，保持旧后端缺字段兼容。额度充足不代表全部准入/原生运行/取消已停止。
- 仅源码/AST及Luna复核，按原维护流程重载并保留正式数据。无测试/Node/浏览器/HTTP/模型/lint/build；不提升AC，完整目标继续。
