# 未完成经验草稿的写入保护

“整理为经验草稿”生成的结论、适用条件、失效条件、版本和操作边界包含 `【请填写…】`。这些占位必须人工补全后才可审核。服务端现在与前端保持一致，拒绝未完成占位、空正文及NUL字符；审核HTTP还拒绝正文包含当前审核凭证，错误只返回固定中文，不回显凭证或正文。

新审核在持久审核登记前检查；原首次写入和明确失败后的显式重试在创建新出站意图前再次检查，直接调用提交协调器也不能绕过。非法内容不会产生新的写入意图或原生PUT。不更改原正文、摘要、审核ID或数据库结构，不迁移已有数据。

原有 `intent/pending` 仍只读核对原提交；历史详情、已提交内容和删除墓碑不被回写或清理。历史未完成 `approved/failed` 正文的新写入会被拒绝，不能以旧审核身份自动写入；原记录保留供人工核对，不静默改正文或重新执行编码。新规则不代表已经清除了可能存在的历史不合格内容。

单项审核复用原批量路径的当前凭证检查：按钮禁用，正文旁提示原因，提交事件在生成审核标识和本页防重记录前再检查。已审核正文仍只读，提示不会要求用户修改历史记录。

该检查不推断任意经验是否真实、适用或过期，也不扫描所有秘密。失效条件仍需人审和原生能力处理；没有新增过期协议、索引、记忆权威库或角色阻断，不以此宣称完成PRD的完整过期、检索和项目隔离要求。

仅源码、三个Python AST和指定gpt-6-luna独立静态复核；没有测试、Node、HTTP、浏览器、模型、lint/typecheck/build或真实记忆写入。功能及原生闭环仍待验收，完整PRD/AC状态保持。
