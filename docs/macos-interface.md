# 简洁的 macOS 风格工作台

2026-10-23按用户指定方向调整扩展前端五个页面：运行工作台、流程搭建、人工审批、记忆审核、Agent团队。共享styles.css统一浅灰侧栏、白色内容面、系统中文字体、蓝色主要操作和细分隔线；局部CSS使用相同变量。没有添加桌面假窗口按钮、外部字体、图片依赖或新前端框架。

## 阅读与操作

- 每页用具体功能名和短说明，先说明作用和操作顺序；移除营销眉题与无意义分区编号。
- 运行工作台先连接、选择流程、填写任务输入，再启动和查询进度。触发去重标识默认生成，放在“高级选项 · 防止重复启动”；未知结果仍保留原标识，不改变幂等行为。若原生表单校验发现折叠字段问题，展开该字段的折叠区。
- 任务中心默认展示角色、项目、节点及执行/验收/记忆状态，完整标识在“查看任务标识”中展开。精确项目/运行筛选收起为明确入口；从运行详情进入会展开范围并清除旧状态筛选。筛选回显、整页身份与分页回执核对不变。
- 任务详情保留关键状态与停止/审批/未知说明，用量、执行限制和预算收进“用量与执行设置”；运行详情将原/恢复输出收进“运行输出”。原始结果与证据、事件和执行身份仍可展开查看，不删除服务器记录。
- 编辑器突出选择流程、编辑节点、保存和发布，将归档/审计和较长技术内容收起；归档未知时的核对按钮仍可访问。
- 审批区分流程节点决定与执行权限；记忆页说明人工核对后写入角色记忆，删除/索引未确认等重要提示保留；团队页只管理组织关系，不暗示权限继承。

保留原DOM标识、认证、表单类型、审批对象、动态容器、取消保护和业务调用。窄屏导航完整显示，页面改为单栏，长标识换行，控件可键盘访问。原生记忆、QwenPaw/Sim源码及模型配置没有修改。
