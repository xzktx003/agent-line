# 节点执行限额配置实施计划（2026-10-23）

PRD 13.3要求节点失败处理可配置执行超时和明确次数上限。现节点任务已有limits准入/超时/持久计数，但图形编辑和自动发现固定3600秒/3次。本轮只接通现有能力，不新增调度器、依赖、上游补丁或记忆引擎。

1. 提取现有limits数值校验为纯函数，任务入口仍要求完整工作流身份；保持原边界与默认值。
2. Agent图配置可选limits，省略时不改旧图/旧发布哈希。编译与解码保留原值；发布沿现有策略复制冻结；运行账本只接受相同有界数值。
3. 自动任务发现只读原运行冻结策略；有limits使用原值，无limits继续3600/3。非法原值拒绝登记，不从当前草稿/角色配置补值。
4. roles接口显式声明nodeLimitsSupported:true。中文编辑器提供可选表单并在应用/保存/发布核对整数范围，旧后端未声明时不静默剥离已存在配置。
5. 时限是单次实际提交的截止时间，次数是同一流程运行/节点跨循环与重试的实际提交意图总额。不是自动重试次数，未知受理不退款；图推进继续由Sim负责，现有总运行预算另行适用。

用户最新约束：不新增或运行测试，不运行浏览器、Node、lint、typecheck、HTTP或模型探针。仅源码阅读、Python AST解析与配置/文档静态核对。没有部署或验收通过声明；完整PRD状态保持进行中。
