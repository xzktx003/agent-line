# 条件比较值数值边界修复计划

PRD7.4要求按明确结构字段可靠分支。当前expression只检查math.isfinite，而Sim原生JavaScript会舍入超大整数；前端Number(raw)也会先转换。将比较常量限定为有限且绝对值<=9007199254740991，超大业务编号用文本等值比较。范围内普通小数保持IEEE754语义，不承诺任意十进制精度。

只改后端规则验证和前端应用/保存预校验，不改安全范围既有规则生成的JS、marker、冻结规则或原运行。历史超范围规则拒绝重新编译/发布，不静默改值或改类型；后端无权改已发布原图。规则源实际运行值的现有类型/有限检查不改，不宣称本增量识别上游已经舍入的数据。

无新增测试、Node、浏览器、HTTP、模型、lint/typecheck/build。只源码/AST与Luna静态复核；装入后端按原空闲维护重载/数据摘要检查，不将部署当条件分支真实验收。
