# 复制已有流程为新草稿

从 QwenPaw 的“工作流工作台”进入流程搭建，打开已保存且当前界面支持的流程。
展开“复制为新草稿”，填写名称并点击“创建副本草稿”。新流程打开后核对内容，
点击“保存草稿”才把副本内容保存到 Sim；创建后关闭页面会丢失尚未保存的本地内容，
不能把空草稿当成已完成复制。

复制保留当前加载的节点、连线、位置、同项目角色绑定与记忆策略。新图有独立的
Sim workflow ID，保存时经原编译器生成新命名空间下的原生节点 ID。它不复制源
发布绑定、运行记录、Agent 或记忆，也不会自动发布或运行。源图及其发布版本保持。
此入口只在同项目内复制，不是去敏的便携模板导出或跨项目迁移。

实现只改扩展前端，复用原 create、GET、save 与操作查询接口，没有新后端端点、
数据库表、服务或依赖。QwenPaw/Sim 官方源码、QwenPaw 原生 ReMe 与运行配置保持。

创建或保存结果未知时只查询原操作，不换编号重投；查询确认创建后也不自动保存。
读取到副本已有内容时展示实际草稿，不用源快照覆盖；返回源 ID 或草稿身份不符时
不载入副本。副本快照只在页面内存，退出或切项目清空，迟到请求不能恢复敏感内容。
不支持的原生图仍保持只读，不能以复制绕过保护。复制的是当前加载的草稿快照，
不会在创建时把其他编辑者刚修改的源草稿偷偷替换进来。

  均保持。仅两条authoring修改：一次create、一次save；没有publish/run/Agent或记忆操作。
