# 升级证据输入校验计划

修复原只读upgrade准入的JSON/字段歧义，不执行升级、探针、Git命令或候选代码。保留九项强制探针、双组件固定SHA和文件摘要绑定。

锁文件、CLI manifest及证据使用最多1MiB普通文件、单次有界读取，解析拒绝重复键、非有限数和坏编码。摘要与JSON核验使用同一份证据字节。schemaVersion严格整数1，observedAt为带时区ISO时间或有限正Unix秒，不接受布尔/无时区/未来超五分钟；details只接非空文本或对象。时间检查为语法和时钟合理性，不新增证据年龄准入政策或真实性认证。

输出status限制固定枚举，所有错误仅固定原因，不打印原解析异常、键名、值或证据正文。有效既有ISO时间与文本details保持兼容。仅源码/AST与指定Luna复核；不新增/执行测试、Node、HTTP、模型、Git完整性检查或重启服务。
