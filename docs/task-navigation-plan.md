# 任务中心追踪入口

继续PRD13.7，在既有任务与运行目录之间补操作入口，不新增API、状态、框架或调度。

- 首页每条已有任务增加“查看任务详情”，将固定任务ID放在同源运行页fragment；不携带凭证/正文，不自动查私有记录。
- 运行页严格核对fragment，仅预填任务表单并清除旧详情/取消目标。未授权仍先授权；用户点击查询后沿原接口检查权限和身份。
- 节点详情可显式查看同一项目/流程/运行的其他节点任务，复用现有筛选与目录；不从标题猜运行，不改执行状态。
- 抽取原运行详情的筛选填充为同页函数，维持原按钮的迟到响应/绑定检查，避免两套筛选语义。
- 只做源码复核，不运行测试、Node、浏览器、HTTP、lint或构建；静态前端直接由已有挂载提供，无后端重启或数据操作。
