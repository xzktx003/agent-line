# 画布缩放与节点拖动

流程搭建页增加放大、缩小、适应全图和定位选中节点。缩放范围25%–400%，只改变当前页面视图，不修改流程、不触发保存或发布。重新读取、切项目或退出清除视图。手机画布按可用宽度显示全图，细节可放大，也可用原节点列表和坐标表单进行精确编辑。

拖动使用浏览器Pointer事件和SVG坐标转换，缩放后仍按流程坐标移动。位置沿用原0–3000边界，连线随节点预览更新。释放后标记草稿未保存；按Escape、pointercancel或失去捕获恢复本次起点，保持此前未保存状态。未应用的节点表单阻止拖动并保留内容。忙碌、操作结果未知或不可编辑时禁止拖动。保存仍使用原接口、状态摘要和真实图编译器；没有新增画布数据源、服务或依赖。

真实浏览器1440px和390px检查通过，API全部拦截：缩放不制造脏状态、拖动只改本地、主动保存保留新坐标且编译有效、连线身份保持、Escape撤销、未应用表单不丢失、重新读取视图重置、选中节点定位居中和退出清空。每种宽度只保存一次模拟请求，真实服务写入/模型调用均为0。证据var/canvas-interactions-20261022/browser-report.json及截图。

初次手机截图发现继承的640px最小宽度让“适应全图”仍裁掉末端；已改为实际可用宽度，集中复验通过。此处是完整PRD画布能力的一部分，更广图形组合、实际主入口集成及其余完整PRD仍需继续，不能提升整条画布验收。

## 拖拽添加、连线与自动布局增量

选好节点类型后，可将“拖拽添加当前类型”拖入画布；保留“添加节点”按钮作为触屏与键盘入口。只有当前页面发起的拖动身份有效，外部拖入、切项目后的旧拖动不创建节点。原唯一开始节点、并行/循环形状限制和200节点上限继续执行。

节点右侧圆点可以拖到终点；条件或循环先在既有连线表单选择规则、否则、循环体或完成出口。开始拖动时固定出口，重复连接同一出口被拒绝。Escape取消不改图。圆点支持键盘转到原连线表单；表单仍是准确配置分支的等价入口。多条相同起终点的分支曲线和文字错开，避免规则与否则重叠。

自动布局只修改节点位置，不改节点身份、配置、连线、变量或记忆策略。按拓扑层次排列，长链和宽扇出折入有界网格；最多200节点，坐标0–3000，矩形不重叠。空图、重复节点、悬空边或普通循环拒绝布局，保留原稿。未应用表单时先处理表单；布局后仍需主动保存。

4项布局检查及既有模板共10项检查通过（1.318秒）；真实编译器验证分支汇合语义保持。1440px/390px真实浏览器验证拖入人工节点、添加条件、4次指针连线（含规则/否则）、重复出口拒绝、布局、编译保存与重新读取，服务API全部拦截；旧拖动缩放两宽度与模板6场景也通过。集中视觉修正把布局间距改为230/110并错开分支线，保留窄屏换行。

额外边界修复：拖动中已移动的位置也纳入未保存退出确认；非活动pointer的取消/失捕获不取消当前拖动。两宽度真实指针探针均覆盖这两个边界，助手只读复核提出的问题已修。

真实Sim集成另使用独立日志及自有草稿，当前源码AuthoringAPI保存浏览器生成的4节点4连线，原生读回各节点字段、配置、坐标、分支和其余文档字段一致，状态摘要与保存回执一致。初次断言发现原生会重排节点数组，已保留此失败说明；后续只读取原已保存身份，按ID核对完整字段，不重发保存。证据var/canvas-authoring-20261022/{save-intent,native-readback,native-report}.json。最新浏览器复验重新生成的随机节点与调整后间距未覆盖原已冻结保存意图；真实保存证明限该原始测试图，不扩大为全部新图验收。

主静态服务editor.html/editor.js/canvas-layout.js均HTTP200且字节与仓库一致，Cache-Control为no-store；后端未重载，因此目录搜索等后端增量仍需集中部署。没有发布、启动流程或模型调用，没有修改主日志/正式角色/原生记忆。浏览器/真实探针分别为`.venv/bin/python -m probes.ui.canvas_authoring`、`.venv/bin/python -m probes.sim.canvas_authoring`；后者重开只观察原冻结操作，不能删除其意图文件后重新提交。
