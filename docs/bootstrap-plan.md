# 从零依赖准备与镜像输入修复计划

新增仓库内标准库bootstrap入口，默认plan仅输出固定步骤，不执行安装。显式install仅为全新环境拉取缺失的锁定上游、创建新.venv、按现有requirements-runtime.lock.txt安装依赖，并从锁定QwenPaw的git archive构建安装；不在上游工作树生成构建文件。现有环境存在即拒绝，已有checkout只核身份不fetch/reset。安装失败保留本轮私有日志和未完成环境，不自动重跑/修复/删除用户目录。

安装缓存、临时目录和日志全部在本仓库var下；不改全局配置、系统Python、服务配置、账户、记忆或现有服务。依赖构建所需工具来自上游build-system，不新增业务依赖；锁文件仍是版本锁，不宣称有hash校验或完整跨平台复现。

修复executor/build_image.py的硬编码本机镜像输入和自动改正式config行为：改显式完整镜像ID与全新输出目录，生成独立构建记录，不自动替换现有配置。不构建/运行镜像，不放宽只读/隔离策略。安装手册明确Console、Sim、Codex隔离及项目接线顺序和仍缺的真实首次安装验收。

本轮只修改源码、文档和AST审阅，不执行安装/构建、测试、Node、Docker、HTTP、模型或现有服务重启。完整PRD不据文档或新脚本提升验收。
