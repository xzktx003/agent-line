# 固定版本只读运行图

在“运行管理”填入原发布绑定与运行标识，展开“固定版本运行图”，点击读取。该入口需要原运行凭证。它显示该运行固定的发布版本结构，不打开编辑草稿，没有拖拽、保存或发布动作。可以缩放、滚动和使用键盘选择节点。

选中节点后显示其已登记任务的执行、验收和记忆计数，每条激活/尝试分别保留。 每条任务在已有依据时另起一行显示阻塞原因：提交中或提交未知、申请取消，以及回执里的启动阻塞或串行等待队列。没有这些字段的已登记任务不新增原因。队列重算不在这张图上进行。点击“查看任务详情”只填写下方原任务查询表单，需再次点击查询才读取敏感详情；不会启动或取消任务。资源退出情况独立显示，负责人ID不代替原生执行任务或Codex会话。

## 项目、版本与任务参数

图读取成功后显示三行：项目、固定流程版本、操作者。前两项只取本次图回执已核对的 `identity.projectId` 和安全整数 `revision`，不用绑定列表里可能已更新的当前版本。提交回执没有操作者字段，因此第三行固定说明未提供，不编造人名。

“读取本次任务参数”沿用现有本地根输入接口。回执身份必须与这次运行图一致，且输入是对象。含当前凭证则禁止展示；正文超过 64000 字节只说明超限。页面写明这不是 Codex 提示词、工具正文或操作者记录。读取失败或身份不符时清除预览。

## 版本与范围

受授权GET `/extension/v1/workflows/{binding}/runs/{run}/view` 首先核对项目绑定与同一提交日志快照中的根运行、历史发布pin。pin必须accepted，input/receipt均与完整规范化发布快照相等，两记录的状态、时间及根规范编码也须有效。固定版本、部署ID和规范图摘要再次匹配后才显示；不要求旧版本仍活动，不读取当前草稿或静默切到最新版本。

没有可核对发布pin的旧静态绑定、原生版本不可用或不属于受支持投影的图，会明确拒绝运行图，原任务目录仍可使用。固定发布结构是当时选定版本的证明，不等于该版本每条分支都实际运行。

响应仅包括节点ID/原生block ID、名称、类型、坐标和连线，以及现有任务库同一项目/流程/运行快照中最多500条任务状态与激活/尝试/负责人身份。任务发布修订和节点映射不一致时拒绝；超过500条明确标为不完整，不选择所谓最终尝试。节点最多200、连线1000、位置有界，不返回图指令、变量、配置、输入、输出、证据或工具日志。

## 观察限制

时间为本地任务记录读取时间。 读取控件旁单独显示连接状态：尚未读取、最近一次读取成功，或读取失败后是否仍保留上次固定结构。这只描述运行图接口的最近一次读取，不表示连线已命中，也不把失败说成 Codex 断开。默认手动刷新；读取有效图后可选[每10秒自动更新本地节点状态](run-view-refresh.md)，后续只读取本地摘要，不重新读取原生图。不主动查询每个Agent/Codex的实时状态。原生节点执行状态、条件命中和连线执行证据保持unknown，箭头只表示定义方向，不高亮成功路径。没有任务记录不能证明原生节点未运行，Agent执行成功也不能推出其他节点或整个业务完成。

也可手动[读取原生流程状态与本地资源摘要](native-run-summary.md)，分别核对整体流程状态、代表性等待点和本地资源退出记录。该查询不进入自动更新，不请求原生输出/trace，也不把流程状态推导为Codex活动或独立验收结论。

退出、修改运行标识、选择其他运行或重新查询会清图并废弃迟到响应。私有接口沿用原Bearer与项目scope，匿名首页不扩大。没有新增表、迁移、依赖、服务、执行调度、模型调用、Agent创建或记忆修改；QwenPaw和Sim源码不改。

两Python AST及Luna前后端只读复核；没有新增/运行测试、Node、浏览器、主动HTTP、模型探针、lint、类型检查或构建。部署仅核对进程/socket/启动日志和数据保留，不能据此认定交互、原生路径或完整PRD13.4通过。原生节点与路径观察仍属于未完成范围。
