# 系统能力与兼容状态

运行管理页提供默认折叠的“系统能力与兼容状态”。使用原运行凭证授权后，点击读取才查询当前摘要；不会自动轮询或运行模型，也不会打开执行准入。首页已有任务/服务列表仍然无需连接。

`GET /extension/v1/capabilities` 复用原 Bearer 认证及 `execution_state()` 就绪证据核对，读取原任务库恢复/维护保护。响应是观察时刻的只读摘要，后续操作仍执行原权限和准入检查。返回 `Cache-Control: no-store`，不返回令牌、项目列表、角色正文、部署路径或原始上游错误。

已有就绪证明时，原证据核对会读取本地文件、进程和 Git 状态，并查询原生执行绑定描述；这不是纯离线摘要。核对时延或上游查询失败可能使能力降为未知/证据失效，不能绕过核对以显示允许执行。该路径不启动模型。

- `execution`：受控节点执行能力、是否允许新节点任务、恢复保护与固定阻断原因。这里的允许只表示当前执行能力和保护条件，不保证任意工作流或项目能启动。
- `services`：工作流、流程编辑、审批、记忆审核、触发入口模块是否在本实例中配置。模块存在不等于原生服务健康，更不授予当前运行凭证编辑、审批或记忆权限。
- `apiContractVersion`：适配接口契约版本，不能当作 QwenPaw 或 Sim 的产品版本。
- `versions`：当前尚无可信运行版本来源，QwenPaw 和 Sim 均明确返回 `null`，`versionSource=not_observed`。不使用 checkout 锁定 SHA 冒充实际运行版本，不宣称升级已验证或完全兼容。

- `nativeExecutionIdentity`：当前适配版本不把 `roleSessionId`、`executorAgentId` 写入执行身份。能力检查明确返回 `not_written` 及原因；可核对替代是任务上的角色 ID，以及仅在已记录时有效的上游任务号。该字段只描述能力，不补造身份，也不改任务存储。旧进程没有此字段时，页面仍接受原摘要。


旧后台缺少此接口时，前端明确显示能力摘要不可用，不从失败推断模块不存在。退出或更换授权身份清空摘要，迟到响应丢弃。没有配置修改、权限扩展、原生版本探测、升级按钮或新的服务连接表单。

实现只做源码阅读、Python AST 和指定 gpt-6-luna 独立静态复核；没有测试、Node、浏览器、HTTP、模型、lint、类型检查或构建。真实接口和页面仍待验收，完整 PRD 与 AC 状态不提升。
