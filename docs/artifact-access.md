# 按原验收记录核对并下载产物

在运行管理中查询任务详情，展开“产物与独立验收记录”，对满足条件的文件点击“核对并下载产物”。页面不自动读取文件，不执行测试；下载不会改变执行、验收或记忆状态。单个文件核对通过不代表其他文件或独立测试通过。

原任务须执行成功且资源已释放，验收已结束为passed或failed。只有冻结verificationPolicy与唯一正式验收回执中核对通过的artifact_sha256条目可读取。整体验收失败时，其他独立通过的文件仍可检查。无正式回执、未通过的文件、身份或策略不符均不可下载。

授权GET `/extension/v1/node-tasks/{task_id}/artifacts/{check_index}` 仅接受任务和原检查序号，不接受客户端路径或摘要。沿用任务项目权限；原AutomaticVerifier只校验历史回执，不调用执行器。原nofollow文件描述符读取增加可选有界捕获，普通验收调用保持原元数据行为。返回前重读任务并核对原执行身份、冻结请求、验收状态和唯一回执。

当前文件须与原回执的SHA-256和大小一致；读取过程检查普通文件、符号链接、大小和文件变化。单次最多1MiB，超过返回413，文件不可用或证据不符返回409，不返回部分正文。它读取的是当前路径上仍与原记录匹配的字节，没有另建历史文件存储，文件改变后不能恢复旧版本。

响应为固定身份、相对路径、摘要、大小和base64正文，no-store。前端核对身份、原检查序号、路径、摘要、大小及规范base64，采用application/octet-stream Blob发起浏览器下载，临时URL及时撤销；不以内联HTML运行，不在URL携带凭证。摘要由服务器重算，页面不声称浏览器独立计算摘要。退出、切换任务或重绘后丢弃迟到结果。浏览器是否实际保存由浏览器确认。

沿用macOS简洁控件和原折叠区，无新框架、依赖、数据库或服务，不改上游QwenPaw/Sim/原生记忆。只做源码审查和Python AST解析；未运行测试、Node、HTTP、浏览器、模型探针、lint/typecheck/build，实际权限、下载和页面交互仍待验收。完整PRD及AC20/22/13保持。
