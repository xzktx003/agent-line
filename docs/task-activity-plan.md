# 任务中心时间与最近事件

对应PRD13.7，在现有首页与运行管理的任务列表和详情显示真实登记时间、最近记录时间与最近事件；不将登记、受理或最近事件时间称作执行开始/完成时间。复用tasks.created_at和events最大seq，无新表、依赖、写操作或原生探针。

TaskStore.get/list_tasks在各自读事务内取任务和最后事件，批量目录只读本页任务的事件，原registered阻塞判断复用同一事件。API只添加activity白名单，旧响应缺少时页面明确尚无记录。前端共用时间和事件中文格式化，既有事件列表复用事件翻译；无轮询。

仅源码/AST审阅，遵守禁止运行测试、Node、浏览器、HTTP或模型探针的要求。部署沿用备份/空闲/维护保护的原服务重载流程，不修改QwenPaw或现有记忆。不提升未验证验收状态。

已保存的 role_started 可以提供 startedAt；没有该事件时明确尚无记录，仍不把登记、受理、委派或最近事件称作开始。
