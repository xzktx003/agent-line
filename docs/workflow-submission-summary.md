# 工作流目录的本地提交摘要

流程搭建页的既有目录独立显示两种事实：原生运行次数/最近运行仍由Sim详情提供；本地提交次数和最近登记来自原SimJournal根提交记录。提交受理、意图、拒绝和未知均不表示运行成功，记录更新时间不称为开始/完成时间。摘要覆盖该流程全部版本，不与当前部署版本混同。

后端为本页最多100个原项目已受理创建的流程再次核对所有权，在同一个只读事务内批量读取根提交数量和最大rowid对应的最近登记记录。仅context为空的根记录计数，恢复、发布、审批及触发去重记录不计入；无原生查询、输入或回执正文读取、新表、索引、依赖或状态权威。返回前再次授权，摘要不含工作区路径或凭证。

返回localSubmissions.source=local_root_submissions_all_versions，count为非负安全整数，latest为空或含runId/submissionStatus/updatedAt。原目录仍有原生元数据查询，本增量没有增加原生请求。前端只在字段存在时显示，旧后台保持原样；异常摘要显示待核对，不将未知当零。沿用页面代次与原列表权限，不提供新执行/核对动作。

本轮仅Python AST、源码和Luna独立静态复核，没有测试、Node、浏览器、HTTP或模型调用。部署只验证进程与历史数据保持，不等同界面、并发写入快照或完整PRD运行验收。AC仍20/22/13。
