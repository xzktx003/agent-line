# 任务负责人Agent

授权后的节点任务详情直接显示“负责人 Agent”。展开“流程与执行标识”，可分别查看角色绑定、负责人Agent、流程版本、运行、节点激活、尝试、原生执行任务及Codex会话/回合。私有任务目录的标识折叠区也包含负责人，方便沿运行追踪到具体记录。

负责人来自该任务登记时已固定的payload.roleAgentId。直接登记取服务端项目角色绑定，原生节点发现取已经核对的发布策略；执行分派继续核对原冻结角色与网关。展示不读取最新配置重新解释旧任务，不把角色绑定ID当成原生AgentID，不从任务标题或聊天记录推断负责人。

角色身份是登记事实，不证明该Agent或Codex已经执行。尚未执行的任务也可以有负责人；实际原生任务、Codex会话/回合缺失时仍显示尚无记录，不用负责人填补。旧数据或旧服务没有有效字段时显示“原记录未提供”，不据此更改执行、验证、记忆或就绪状态。

现有受授权任务列表/详情投影增加roleAgentId（无效或缺失为null），仅允许有界非空字符串。匿名首页白名单不扩大；不返回工作区、原生配置或角色正文，没有新API、数据库写入/迁移、模型调用、Agent创建或记忆操作。

静态源码链路核对及只读SQLite计数确认现有19任务均已保存有界负责人ID；不打印身份或私有载荷。Python AST和Luna源码复核，不运行测试、Node、浏览器、HTTP、模型探针、lint或构建。这些证据不代表当前页面或全PRD已实际验收。
