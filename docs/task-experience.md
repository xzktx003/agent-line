# 从历史任务整理经验

本增量复用既有记忆审核、提交日志与 QwenPaw 原生记忆，不增加记忆引擎、模型调用或技能权限。当前仅完成源码接线和静态审查，未运行测试、浏览器、探针或真实记忆写入，未重载主后端。AC-67 继续为 in_progress。

## 操作路径

1. 任务已结束且执行资源确认释放后，任务详情提供“整理经验候选”；已提交记忆的任务提供查看来源记忆入口。
2. 同源链接 fragment 只传项目、角色绑定和任务标识，页面读取后立即清除。记忆页仍需独立审核凭证；项目与角色绑定必须唯一匹配当前授权，随后重新读取来源详情和原审核记录。目标无权限、缺失或不匹配时不改读默认角色，需明确重新选择。
3. 核对任务输出、证据和执行/验收结果后，点击“整理为经验草稿”。仅填入来源元数据和证据 SHA-256，不复制输出或工具正文。失败、取消和未通过验收仍保留原结论。
4. 人工补全经验结论、适用条件、失效条件、适用版本与操作边界。覆盖未提交正文需确认；生成后清除审核勾选，待填写标记未补完不能提交。最后仍通过原审核确认写回原生记忆。

草稿仅存在页面内存，退出清空。已有审核正文不可由此覆盖；未知提交沿用原决定与查询流程，不自动重发或重新编码。本入口不把经验安装成可执行技能，也不修改原生角色工具权限。

## 来源一致性

来源详情新增顶层 `evidenceSha256`，摘要基于完整原始任务证据；页面仍只展示有长度限制、移除资源工作区路径的预览，因此不能对预览文本重新计算摘要冒充完整证据。

审核请求可携带 `expectedEvidenceSha256`。服务端在现有 `verification_scope` 内重新读取任务，核对项目/角色、终态与资源退出，比较来源摘要并登记不可变审核快照；与后台自动验收、取消共用任务锁。摘要变化返回 409，且不预占审核记录。登记后释放任务锁，再进行原生记忆网络调用，不让网络等待占住验收锁。原审核重放继续使用最初的人审来源快照，不把后来的证据替换进去。

该字段为可选，以兼容旧手写审核客户端；经验草稿只有在来源含合法摘要时开放。旧后端未返回摘要时显示缺失提示并禁用整理按钮，原手写路径保留。主后端尚未重载，不能将源码能力当作已部署结果。
