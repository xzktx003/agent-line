# 运行图自动更新本地状态

先按原操作读取固定版本运行图，再按需勾选“自动更新节点状态（每10秒）”。 自动更新暂停、页面隐藏或正在交互时，连接状态保持上一次完成的读取结果，不改成断开。默认关闭。自动更新只读取本地已登记任务的最新状态，不会启动工作流、调用模型、运行测试或反复下载原生发布图。

固定图仍由原GET /view首次读取与核验。后续GET /view/state必须提供该图的graphSha256，沿原Bearer和项目授权核对精确历史发布pin、根提交、修订与摘要；响应只含同一身份、最多500条任务白名单、覆盖和读取时间，没有图配置、输入、输出或工具正文。任务必须属于冻结Agent策略节点，完整图初次读取还校验图节点交集。服务端不新增图缓存或数据库迁移。

两端点共用原严格历史pin核验及任务投影：pin为accepted，input/receipt等规范完整快照，根记录规范编码和时间/状态有效；固定图初次读取继续核对原生部署ID和graph hash。刷新摘要不是权限凭证，原服务身份/项目scope仍是授权依据；两个响应禁止缓存。

前端只接受与已核验图全部身份字段一致的状态快照，再用原图核对每条任务归属。更新一次结束后才安排下一次，避免同身份并发积压；关闭页面展示区域或切后台暂停，退出/换凭证/换运行清理缓存、计时器和自动选项。取消自动勾选后，在途自动响应也不能继续更新当前界面。更新失败停止自动，不把最后成功快照当作当前确认状态；需要用户手动核对。图交互期间避免抢焦点，保留已选节点、缩放及滚动；再选节点取最新有效快照，失败后不能重显首次读取的旧状态。

这里的“更新”只指本地任务记录，原生节点执行和连线命中仍unknown，500条上限仍可能截断。最后成功读取时间不是Codex活动证明，网络恢复也不意味着业务已恢复。真实原生路径追踪与完整PRD仍未完成。

仅源码/AST与Luna静态复核；没有新增/运行测试、Node、浏览器、主动HTTP、模型/探针、lint或构建。未主动请求新增状态接口，部署核对不能当作实际交互或完整验收。
