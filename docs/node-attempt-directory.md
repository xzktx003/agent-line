# 同节点全部激活与尝试

任务详情提供“查看此节点的全部激活与尝试”，填入原任务中心的项目、流程、运行、逻辑节点范围；清除旧业务任务和执行状态条件，让同次运行同节点各状态任务都可见。原“查看同次运行的其他节点”清除节点范围，业务任务跨运行入口也清除节点范围。不新建任务、attempt、Agent或模型调用。

授权GET /extension/v1/node-tasks新增可选nodeId，必须同时提供projectId/workflowId/runId；匹配原冻结payload.workflow.nodeId，既有项目授权、任务ID游标、状态和业务任务叠加条件保持。游标必须属于完整所选范围。原无nodeId请求/filters回显保持原格式，匿名首页无新增字段或能力。

列表先核对完整filters回显及每项workflow.nodeId，再展示；旧后台忽略参数时拒绝将整个运行当同节点结果。无匹配仅表示本地当前筛选无记录，不证明原生未执行。激活和尝试均来自原登记，不猜测重试顺序，不将任务ID分页排序当时间顺序。详情入口仍需明确点击查询原任务；节点过滤不自动恢复、取消或重提。

节点标识为1–256字符，去除首尾空白后不能为空；前端手工筛选沿原规则trim。原代次检查与退出清理覆盖新字段，改范围会清旧列表并禁用旧分页。界面沿原高级范围折叠区和中性按钮，无额外卡片或新页面。

本轮仅源码/两个Python AST及Luna静态审查；未新增或执行测试、Node、浏览器、HTTP、模型、lint/typecheck/build。部署维护检查只证明进程装入与任务/配置摘要保持，不证明真实循环、多attempt、迟到回执和界面验收。完整AC20/22/13不变。
