# 条件比较常量的数值边界

Sim的条件由JavaScript求值，Python能表示的大整数不一定能原样进入JavaScript。原规则只检查有限性，直接API或前端输入超大整数时可能改变比较常量。本增量将所有数字比较常量限定为有限且绝对值不超过9007199254740991（JavaScript MAX_SAFE_INTEGER）；布尔与文本比较沿原规则。

后端expression在生成代码前检查范围，再检查有限性，任意大Python整数不会进入math.isfinite导致溢出；拒绝码condition_number_out_of_range。前端应用节点配置以及保存/发布的validateGraph均提前显示中文说明。订单号/单号等需精确保留的大整数应作为字符串，用等于/不等于比较；不自动换成文本或截断。

范围内规则生成的原生JS和规则marker字节不变，不迁移旧草稿、发布版本、回传或运行。历史超范围规则重新编译/读回核验时会拒绝并保留原图，不能偷偷更改值后覆盖；现有运行仍以原冻结版本执行。此修复只限制比较常量，不添加新运行时表达式或替换Sim调度器。

普通小数仍遵循IEEE754双精度，不提供任意精度十进制。开始输入或上游原生响应若已被JavaScript舍入，此增量不能恢复原始数字；实际源字段继续使用原类型/有限性检查，自定义结构化结果保持既有安全数字范围。不要据此宣称所有业务输入数字精度已验证。

本轮仅Python AST及gpt-6-luna源码静态复核，无新增或执行测试、Node、浏览器、HTTP、模型、lint/typecheck/build。空闲维护重载仅证明源码装入及数据摘要保持，不证明真实Sim分支功能验收，完整AC20/22/13保持。
