# 节点角色配置摘要

流程搭建中选择Agent节点及既有角色后，角色旁显示只读摘要，帮助确认由谁负责、访问方式、复用的原生记忆及独立验收方式。角色名称仅用于阅读，工作流仍保存稳定角色绑定ID，不创建或重命名原生Agent。

现有受授权项目roles接口逐项添加可选details，旧字段和身份保持：名称、已配置职责（规划/开发/审查）、配置访问（只读/委派）、固定角色修订、QwenPaw原生角色记忆、经过既有策略校验的验收ID/产物数/命令数。它不返回测试命令、环境变量、产物内容或完整配置。

执行摘要复用服务启动时已经验证的原生execution-binding描述符：Codex后端、固定执行Agent ID；只有原生描述符明确给当前角色read-only/never覆盖时才显示该值，其他默认权限不猜测。BoundRoleGateway新增字段仅作展示，不参与权限判定、相等性、提交载荷或幂等身份。缺少或非法的可选展示标识不改变原启动/执行行为。

服务装配交叉核对gateway和编辑器/服务两套现有角色注册项的项目、绑定、角色、固定修订及工作区，再给AuthoringAPI只读摘要。不匹配时不提供执行摘要，不扩大角色发布或执行资格。模型ID在当前原生描述符中没有提供，明确为空；不读取本机原生私有配置去冒充远端事实。工作区只说明使用项目已登记工作区，不泄露宿主路径。

配置摘要和原生启动时快照不表示当前实时健康或执行就绪；角色变化后仍由原发布核验/执行preflight/就绪机制决定能否新执行。记忆范围不因此扩大，仍保留QwenPaw官方角色、会话和ReMe。需要模型、默认沙箱/审批及原生健康的完整当前信息时，仍需官方支持接口后续补齐。

前端旧后端缺少details或遇到未知结构时，只显示摘要未提供/待核对，不让未知展示元数据改变原有效角色选择和保存/发布资格。所有显示由固定中文标签和textContent构建；角色刷新/切换/退出/非Agent节点清理旧摘要，不清除未应用字段、格式或限额。无新请求、写入、本地存储、依赖或新管理页面。

仅源码阅读、Python AST与独立Luna静态复核；没有新增/执行测试、Node、浏览器、HTTP、模型、探针或lint/typecheck。仅补充13.3部分真实可得配置，完整节点模型/策略/健康、编辑器交互及完整PRD仍需实现和实际验收，AC状态不提升。

主要代码：agent_line/execution_runtime.py、authoring_api.py、service.py及frontend/editor.js/html/css。展示逻辑复用现有角色读取，不新增常驻组件或改变原生记忆。
