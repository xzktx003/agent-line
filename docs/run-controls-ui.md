# 中文运行控制工作台

仅当授权 GET 原运行返回严格 supported 控制摘要时，显示暂停后继任务、继续、申请停止按钮。控制状态不替换原 execution/resumption；任务数量、未知任务与资源未释放数量单独呈现。暂停先弹出选择：活动任务继续，或只申请中断活动任务。继续后说明活动任务仍在执行；中断说明尚未确认停止。没有记录选择的旧暂停只说明无法判断，不显示为已停止。停止必须经过当前绑定/运行/版本确认框，说明不删除角色或记忆，也不把原生取消当作 Codex 已退出。确认期间选择或版本改变则拒绝旧确认。

每次用户动作生成一个 operationId，保存本页面内存 pending 后才发送一次 POST。返回摘要必须匹配 operationId 且版本前进才解除 pending；网络丢失/不明保持未知，只能 GET 核对。GET 即使出现更高版本但不同 operationId 也不推断原请求失败，不能再次控制。409 明确要求重新查询最新状态，查询前隐藏按钮。页面退出清空凭证、结果和选中运行；非秘密 pending 标识仍在本页内存防重，不写 localStorage/sessionStorage。未知历史只能继续核对，页面不提供强制重提按钮。

## 离线验收

`probes/sim/run_controls_offline.py` 完全拦截 HTTP，以固定 fixture 验证，不启动服务、真实流程或模型，不真实停止任务。覆盖 GET 前隐藏、暂停/继续、版本冲突、丢回执不重投、更高版本但不同操作仍未知、GET 精确匹配解除未知、停止确认取消与确认、原生取消不代表资源退出、不支持隐藏、退出清空、storage0。5 次模拟 POST，真实 HTTP 为0，CSP/pageerror为0。

## 验收任务计数补充

`resourcesUnreleased` 仅标作“编码资源待确认”。只有 `verificationPending`、`verificationCancelRequested`、`verificationCanceled` 全部为非负安全整数时，摘要追加“测试验收待确认 N · 验收停止待确认 N · 已取消验收 N”。这些是任务数量，不是容器或进程数量。旧服务器完全未提供字段显示“测试验收状态未提供”；部分缺失、布尔、负数或字符串显示“测试验收状态待核对”，不会伪作零，也不禁用原本可用的控制。

本轮同一离线探针增加上述正常、旧接口、部分缺失及三种错误类型检查，原未知回执不重投、版本冲突、退出清空等检查继续通过。共 14 组覆盖项，仍为 5 次模拟 POST、真实 HTTP 请求 0、CSP/页面错误 0。桌面和手机截图已更新；一次视觉复核 93/pass，摘要自然换行、手机无横向溢出。此结果只证明 fixture 契约行为。

## 局域网 HTTP 随机标识兼容

运行控制的 operationId 在 crypto.randomUUID 不可用时改用 crypto.getRandomValues 生成 16 字节随机值，格式 control-32hex，不使用 Math.random。离线浏览器显式将 randomUUID 设为 undefined 后完整复跑暂停、继续、停止、版本冲突和未知防重；5 个模拟请求的标识均格式正确且唯一，未知提交仍保留原标识等待 GET 精确核对。最新报告 `.omx/state/run-controls/offline-report.json` 为 15 组覆盖，真实请求 0、CSP/页面错误 0。JS 语法检查与探针编译通过；本轮仅功能兼容，不改布局，沿用现有视觉裁决。

## 暂停时的活动任务选择

离线探针改为打开 `/workbench/runs.html`，因为运行凭证和控制按钮在这个页面。授权文案核对为“操作已授权”，查询使用查看运行表单的提交按钮。打开暂停框后返回不会提交；选择继续后提示活动任务继续执行。回执改成未记录时，提示不能据此判断，并且不出现“已停止”。最新报告仍是 5 次模拟 POST、真实 HTTP 请求 0、CSP 和页面错误 0，覆盖项增至 17 组。此结果只证明 fixture 契约，不替代真实暂停或资源退出。
