# 升级准入的证据输入校验

本轮修改只读agent_line.upgrade工具，不执行升级、拉取、Git核验、探针或候选代码，也不切换运行中的服务。强制九项探针、当前/候选双组件固定SHA和文件摘要绑定保持。

## 文件与JSON

锁文件、CLI manifest及每份证据以O_NONBLOCK/O_NOFOLLOW打开，要求最终打开对象是普通文件，最多1MiB并有界读取。证据路径仍先按原contained解析并限制在安装根；该规则允许解析后位于根内的已有符号链接，最终打开的目标不能被替换为符号链接。它不是父目录并发替换的完整防护。

JSON使用UTF-8，任意对象层级重复键、NaN/Infinity以及1e400这样的浮点溢出均拒绝；坏编码或深度过大不会打印原文。证据摘要和解析严格使用同一次读取的raw bytes。超大详情应在有界正文中引用另行保存的证据，不能默默截断后当原文核验。

锁和manifest的schemaVersion必须严格为整数1，布尔true无效。有效旧版manifest无需添加字段。

## 证据字段

observedAt支持带秒和时区的ISO时间（Z或±HH:MM，最多6位小数），或有限正Unix秒；无时区、布尔、无效日历与超出检查时刻五分钟的未来值拒绝。时区的小时/分钟分别限定00–23/00–59。检查使用系统时钟，时钟显著错误时应先处理时钟，不绕过门禁。这里没有新增证据年龄政策，旧证据仍必须与精确版本组合匹配。

details要求非空文本或非空对象，空值、空白和布尔不能充当上下文。状态输出仅passed/failed/unverified，异常原值不会被回显到报告。对外错误只使用固定原因，不输出原解析异常、键名、字段值或details正文。

这些结构检查不能证明mode/live或passed真实，也没有增加签名、环境指纹或自动执行验收。人工编造证据仍不可接受。源码存在和静态审查不能证明升级成功。
