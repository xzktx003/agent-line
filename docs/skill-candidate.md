# 已审核经验转为原生技能候选

本增量只完成 API 与格式化源码，不提供自动安装/启用，也未重载主后端。没有运行测试、模型、浏览器或探针，实际 API 与原生交接均待验收。AC-67 保持 in_progress。

## 工作台入口（源码已接入）

在记忆审核页选择已提交、正文完整且没有删除记录的人审经验，展开“整理已审核经验为技能候选”。独立填写字段，生成后先查看完整 JSON，再勾选确认并下载；下载包装保留项目、角色、任务和摘要，原生创建只使用其中 `nativeRequest`。页面只发起浏览器下载，文件是否保存需在浏览器确认。

生成后可点击“核对原生技能”，查询相同候选在固定角色下的文本摘要和启用状态。修改任一候选字段会清除预览、确认勾选及旧核对结果，须重新生成；换来源、原审核记录刷新或退出会清空全部技能字段和下载对象，迟到响应不能恢复旧候选。不把候选或凭证存入URL、localStorage或sessionStorage。导出与核对失败使用独立提示，不改变原记忆提交或未知结果保护。

旧后端不支持新接口时明确提示，不能把静态页面入口当作接口已部署。本轮只有源码审查，没有浏览器验证。

## 接口

`POST /extension/v1/memories/{binding_id}/{task_id}/skill-candidate` 使用现有独立记忆审核身份。该身份只授权读取所属项目经验并生成候选，不能因此取得原生技能管理权限。请求字段如下，字段名和大小由 `SkillCandidateRequest` 定义：

| 字段 | 内容 |
| --- | --- |
| expectedContentSha256 | 当前人审经验正文摘要，64位小写十六进制 |
| name | 以小写字母开头的小写字母、数字及单连字符名称，最多64字符 |
| description | 单行说明，最多1024字符 |
| version | 单行适用版本，最多160字符 |
| applicableWhen / invalidWhen | 适用/失效条件，各最多4000字符 |
| boundaries | 目录、工具、审批及副作用边界，最多8000字符 |
| steps | 人工核对的操作步骤，最多32000字符 |

空白、NUL 和“【请填写…】”占位字段拒绝。技能不是模型输出的自动升级：步骤由用户明确提供，原人审经验仅作为出处参考。导出总文本限制200000字节，不附脚本、凭据或工具回执。

服务端重新检查任务所属项目与角色、人审记录身份、正文摘要和已提交状态。在原记忆作用域内检查删除墓碑；存在任何删除记录、待写回、未知、失败或内容冲突都不能导出。与删除使用既有角色锁协调，避免在删除过程中提取旧内容。重复生成只返回文档，不登记新任务、审核、记忆或技能。

返回的 `nativeRequest` 是交给固定版本 QwenPaw `POST /api/skills` 的候选请求体，含 `name/content`，显式 `enable:false` 且 `scripts/references/config:null`。响应另含目标项目/原生角色/来源任务、原正文摘要及技能文本摘要。`installed:false` 仅表示本接口未安装；不是原生扫描、安装或运行证据。

## 原生安装边界

### 只读核对

`POST /extension/v1/memories/{binding_id}/{task_id}/skill-status` 接受与候选导出相同的人工字段。后端依据原审核重建完全相同的候选，以已配置原生角色的 `X-Agent-Id` 只读获取 `/api/skills/{name}`，比较完整正文 SHA-256 与真实 `enabled`。没有安装、刷新、扫描、启用或禁用请求。原生查询前后复核人审经验的身份、已提交状态、摘要、授权和墓碑；网络期间不持有本地锁。响应不暴露原生技能正文。

| state | 含义 |
| --- | --- |
| disabled_match | 原生正文与候选完全一致，且当前为禁用 |
| enabled_match | 原生正文一致，但当前已启用；不代表本页授权了启用 |
| content_conflict | 名称存在但正文不同，不覆盖或改写 |
| not_observed | 原生详情返回404，可能有遗留manifest，不能判定可安全创建 |
| unknown | 网络、授权或响应不完整，启用和一致性保持未知 |

`safeToCreate` 始终为 null，当前接口不能排除原生遗留配置。核对只证明查询时刻读取的文本和启用状态，不证明安全扫描通过、工具权限正确或执行有效。人工修改任何候选字段后须重新生成和核对，不能使用之前正文的摘要。

由拥有原生技能管理权限的人检查完整候选，确认对应项目专属角色，以原生身份并设置准确 `X-Agent-Id` 后创建。返回包装整体不能当作创建请求体，应只使用 `nativeRequest`。本扩展不执行该网络操作，不写原生技能目录，不改 QwenPaw。

当前固定版本的重要限制来自源码：原生创建接口默认 `enable=true`，因此候选显式置 false；但 `_register_workspace_skill_entry` 会保留同名旧 manifest 的 enabled。若目录缺失而旧启用条目仍在，false 不能保证实际禁用。安装前确认新名称没有遗留条目，安装后核对真实禁用状态，完成独立人工授权后才启用。尚未具备这个状态核验闭环，不开放自动安装。

原生创建和显式启用均经过安全扫描调用，但扫描是否开启、是否阻断由宿主配置决定，不能称为无条件保护。技能正文中的项目/角色说明是使用约定，真正权限仍依赖原生项目专属角色、工具与目录约束，文本不具备强制隔离能力。
