# Sim输入数值一致性修复

复用原SimJournal和运行入口，在新运行的冻结记录、原生提交意向登记前拒绝无法由Sim JavaScript保持的数值和非法Unicode。允许的数值绝对值不超过2^53−1且有限；大整数编号应以文本传递，不能静默转换。JSON仅原类型，嵌套深度上限64，异常不回显输入。

保留原已登记同键同输入的只读回执路径：先查原记录，已有记录不重发，不因新校验改写旧意向。对新意向再检查一次，避免HTTP入口之外的提交绕过。取消原生流程的空对象保持有效。前端在解析后提前提示大数，后端仍为最终边界；静态批量新配方复用同一检查，不改旧批量身份校验或数据库。

不改变原生角色、QwenPaw记忆、调度器、系统权限或正式配置。源码/AST和指定Luna审查，不运行测试/Node/HTTP/浏览器/模型/lint/build。历史已传入Sim的不安全数值不能自动修复或重新执行，保留原记录核对。
