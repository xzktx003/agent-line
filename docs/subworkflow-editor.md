# 在原编辑器中插入子流程

子流程沿用原流程搭建、保存和发布入口，固定引用同项目的一个已发布历史版本。QwenPaw 的角色、会话和原生记忆继续保留，不增加另一套调度服务。

1. 在流程搭建页打开父流程，先保存当前草稿。
2. 展开“插入固定版本子流程”，读取本项目流程，再明确选择历史版本。
3. 选择插入位置对应的已有连线，以及开始输入、前序 Agent/汇合结果或另一子流程返回值作为输入来源。
4. 需要时添加输入和返回字段映射；字段路径使用点分字段名，固定字符串使用 JSON 双引号。
5. 点击预览，核对节点和连线数量，再加入当前草稿。
6. 沿原按钮保存草稿、发布；加入和预览均不会自动运行。

固定版本的内部节点可调整画布位置，但不能单独编辑配置、删除或改变涉及该组的连线，包括入口和返回连线。需要调整调用时，从同一面板整体移除后重新预览插入；后续普通节点失效的数据引用保留，须手动修复后保存。另一固定子流程仍使用该组返回值时，须先移除依赖组，避免留下无法修改的固定输入。外部节点只能引用该子流程的返回端口，不能绕过返回字段映射读取其内部结果。

普通节点若仍连接子流程入口/返回，或作为固定输入来源，也不能直接删除；先整体移除相关子流程后再调整。前端按固定版本逐条核对内部连线的起点、终点和分支，无法识别的改动保留只读，服务端仍核对完整节点及连线身份。以上保护避免局部删除造成固定组失效而无法继续编辑。

只支持同父图的单层调用，可以串接多个单层调用；含嵌套调用、批处理节点或多个结束节点的来源仍拒绝。父流程保存和发布仍要求来源版本及角色策略核对、明确项目运行预算，并沿原运行准入执行。旧后台未明确声明编辑支持时，包含子流程的图保持只读。

本次只做源码审阅和 Python AST 解析，没有运行测试、Node、浏览器、HTTP、模型、lint、类型检查或构建。实际界面、保存发布与执行仍待验收，完整 PRD 及 AC 记录不因此提升。
