# 原生流程状态与本地资源

读取有效的固定版本运行图后，点击“读取原生流程状态”。这是一次独立的显式查询，不随本地每10秒自动更新触发。摘要分别显示原生整体状态、整体流程是否暂停、暂停信息，以及本地已提交但资源尚未确认退出的任务数量。是否暂停只看本次已返回的原生状态：有暂停记录或状态为 paused 时回答是；其他已知状态且没有暂停记录时回答否。没有具体暂停点不再被说成“未提供”，除非状态本身是暂停。Codex 活动仍只回答未知，不把未暂停或资源尚未退出当成进程仍在运行。

原生状态使用固定workflow/run的官方v2 runs接口，明确includeOutput=false，不请求selectedOutputs、文件或trace。适配器核对身份、已知状态、带时区时间、暂停点计数、64KB响应上限；意外返回输出/文件/trace会拒绝。前端只得到固定白名单，不转发原始错误、费用、输入/输出、工具正文或配置。网络错误、重定向、缺记录或非法响应都不作为“没有执行”或“已经停止”的证明，不重试或重投。

原生human暂停机制也承载Agent结果等待，因此摘要按原冻结策略区分等待Agent结果、业务输入、定时等待或用途未知；不会只凭human称需要用户批准。blockedOnBlockId和contextId只是原生返回的代表等待点，多点并行时不当作唯一阻塞，也不替代原审批记录。自动恢复有待核对记录时只提示，不触发恢复。

本地资源计数排除未提交的registered任务，最多覆盖原500条记录；截断明确显示。它表示已提交任务未确认资源退出，不能证明Codex进程此刻仍在运行。Sim暂停也不代表Codex停止；原生completed不能替代独立验收、记忆写回或业务任务完成。排队状态的startedAt可能是入队记录，按原生开始/排队时间显示，不伪称模型实际开始。

GET /extension/v1/workflows/{binding}/runs/{run}/view/native要求原Bearer/项目授权和已核验图摘要，并复用原严格历史pin/root检查。原生与本地摘要各自显示读取时间，不伪称跨系统原子快照。客户端独立请求代数防止本地自动刷新误废弃响应，退出/切凭证/换运行仍废弃迟到结果；失败清旧原生结论，本地图保持。

项目和固定流程版本来自运行图身份，不在这份原生摘要里重复。任务参数是另一次本地根输入读取，不是原生输出。公开logs详情含完整执行明细，当前不为画布请求该接口。原生节点执行与边命中仍unknown，没有猜测成功路径；完整PRD13.4尚未完成。源契约依据本仓库固定上游的api/v2/workflows/[workflowId]/runs/[runId]/route.ts、lib/api/contracts/v2/workflows.ts与lib/workflows/application/read-workflow-run.ts，只读参考，没有修改官方源码。
