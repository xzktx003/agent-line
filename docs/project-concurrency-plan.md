# 项目并发上限实施计划

给既有项目配置增加可选 maxConcurrentTasks（1–100），由服务端写入新任务登记，客户端不能声明。旧配置/旧任务缺省不添加字段。沿用现有任务payload、工作区租约和领取事务，不增加表或调度器。

在原BEGIN IMMEDIATE领取事务中读取本项目未结束/未释放任务，使用所有未完成任务已冻结上限的最小值约束新领取；正在提交、未知受理和取消待退出均占用，只有释放资源才返还。旧无上限任务仍计占用；旧未声明任务也遵守同项目尚有效的冻结上限。元数据异常拒绝新领取，不按零计算。

私有详情展示当前派生上限/占用/剩余，已有关注事项解释项目容量已满。原角色/工作区串行和其他预算继续生效。仅源码和AST审查，不运行测试、行为探针、Node、浏览器、HTTP或模型。不更改当前正式项目配置。
