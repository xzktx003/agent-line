# 批量人工审核记忆

记忆审核页增加本页待审区。逐项选择已结束且资源已释放的来源任务，读取来源证据及原审核记录，人工填写并核对正文、勾选同意后，点击“加入批量待审”。暂存不写入记忆，不创建角色，不启动模型或编码任务。

同项目最多10项，总正文最多256KiB，单项沿用原生审核的128000字节限制。每项保存明确的项目/绑定/角色/任务、来源证据指纹、完整正文和固定决定标识。包含当前审核凭证的正文会拒绝暂存及发送；若安全显示函数会替换正文，也拒绝暂存，避免预览与实际提交不一致。这不是对任意秘密的完整扫描，仍须人工核对。暂存使用与后端一致的外侧空白规范；预览显示实际待提交正文。修改上方编辑器不改变暂存内容，需移除未提交项后重新加入。已确认committed的项可清除本页正文腾出队列，不删除原生记忆或防重记录；已发但未确认的项不能以清空队列绕过核对。暂存仅在当前页面内存，退出或刷新会清除。

展开待审区核对每项完整正文和目标，统一确认后按加入顺序调用原逐项审核接口。每个实际提交前先登记原本页防重记录；原后端仍核项目/角色范围、证据摘要、审核锁、墓碑、维护准入。只有已提交记录的身份、决定标识、来源摘要与正文匹配，且状态为committed，才继续下一项。committed表示原文件读回一致，不代表索引可见或检索效果已验证。

结果未知、写回失败或冲突时停止后续项。已发送项只通过GET原记录查询，不因404、超时或网络恢复再次POST，也不调用记忆重试或reconcile。待已发送项全部核对committed后，剩余未发项仍需用户再次明确确认才提交。每项独立持久化，不提供跨项事务；前项已写回不会因后项失败自动回滚。

切换来源任务或角色不改变已暂存项；队列禁止跨项目混合。退出身份清除正文、决定标识和可见内容，保留既有本页防重墓碑；旧请求迟到不能恢复内容或解锁新身份操作。若整个页面关闭，以现有原审核目录恢复观察；不声称提供持久批量作业或自动续跑。

改动仅前端及说明，无新API、数据库、调度器、依赖或原生记忆实现。遵守用户要求，只审阅源码，不运行测试、Node、浏览器、HTTP、模型、lint/typecheck或构建，不实际提交任何记忆。批量审核真实业务及记忆过期/冲突/检索评估仍待实现或验收，完整PRD未完成。
