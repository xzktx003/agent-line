# 记忆候选批量审核计划

复用现有记忆审核页及逐项review/GET接口，不增加后端API、存储、原生角色或记忆引擎。用户核对单个来源与正文后加入当前页面队列，同项目最多10项、总正文UTF-8最多256KiB；每项固定来源身份/证据摘要/正文/决定标识。完整正文默认折叠，可删除尚未提交项，暂存不写入。

再次明确确认后顺序调用原逐项审核，每个POST前同步登记现有本页attempt/tombstone，禁止和单项重复提交。每项通过原后端项目/角色/来源证据、审核锁、删除墓碑与维护准入核对。只有回执身份、决定标识、来源摘要和committed正文都匹配才继续；失败、未知或冲突立即停止。已发送项目只GET原记录，不因404或失联重发；未发项目需显式再次确认才可继续。跨项目队列不混合，切身份清空正文和标识，迟到响应不恢复内容。

沿用macOS风格与原页面权限，默认折叠，清楚解释暂存、写回、检索效果的区别。仅源码审阅，不运行测试/Node/浏览器/HTTP/模型/构建，无实际记忆写入或服务重启。
