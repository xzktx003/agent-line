# 原生记忆召回证据核对

在运行管理页查询一个已有节点任务，展开“原生记忆召回与委派记录”，点击读取已有快照。存在可核对快照时，展开“核对预期内容”，输入一段4至256字符的非敏感单行文本，再明确核对。此操作不重新检索、不启动Agent或Codex，不保存用户输入，也不展示原生记忆、查询参数或委派指令正文。

复用原任务、角色、部署与会话身份。原角色gateway仅读取本地ledger保存的父观察，不调用宿主接口。快照先经过原有2MiB、消息、块、调用数量及顺序/回执校验；损坏、重复调用或无法归属的快照拒绝。JSON字符串形式的参数拒绝重复键和非有限值，避免用歧义参数当证据。

接口：`POST /extension/v1/node-tasks/{task_id}/memory-retrieval-evaluation`，原运行Bearer和项目访问范围，严格正文包含 `expectedVersion`、`expectedSnapshotSha256`、`expectedText`。任务版本不符或快照变化返回409，缺配置/快照未知/无法对应返回503，无效或包含当前凭证的预期文本拒绝。原兼容降级的POST保护保持，降级实例可能拒绝此只读动作。读取后再次核对任务版本及原执行身份；没有持久事务跨外部操作，因为不存在外部操作。

响应来源 `cached_memory_retrieval_evaluation`，readOnly=true。只返回任务/项目/版本、角色/会话/父任务、快照指纹、预期文本SHA256、读取时间、固定覆盖范围和计数：

| 字段 | 口径 |
| --- | --- |
| successfulSearches | 此快照成功返回的memory_search调用数 |
| textMatchedSearches | 成功工具结果的字符串值中出现预期文本的唯一召回调用数；不匹配对象键或JSON序列化产生的转义文本 |
| matchedSearchesBeforeDelegation | 在回执对应当前原生执行任务的委派之前已成功返回、且结果命中的唯一召回调用数；同次召回出现在多个委派前只计一次 |
| matchedDelegations | 此前至少一项成功召回结果命中，且本委派指令也包含相同文本、回执对应当前原生执行任务的委派数 |

计数分母不同，不能将召回调用数与委派数直接相除当准确率。匹配为区分大小写的字面子串；不做模型评分、语义判断、分词、排序或归一化。结果中的semanticRelevance与codexInputInjection固定unverified，snapshotCapturedAt仍为null，readAt仅代表本地核对时间。

文本可能在其他上下文出现，工具成功也不等于返回正确来源。某段文本同时出现在工具结果和父角色委派参数中，不证明来自特定记忆、通过自动召回进入实际Codex输入、被实际采用或影响产物。未命中也只表示本快照未观察到，不能证明原生检索失败。完整PRD检索效果评估还需要有标注样本、实际召回结果与相关性/排序判断，本诊断不替代Recall@K、MRR、项目隔离或真实记忆闭环验收。

前端核对任务/项目/版本/父任务/快照及计数边界，改文本、切任务/身份或重读快照使旧回执失效。当前凭证文本不发送。没有新的持久化、浏览器存储、定时器、模型服务、检索引擎或QwenPaw源码补丁。

证据限于源码、指定gpt-6-luna静态审阅和3个Python AST解析。没有运行测试、Node、浏览器、HTTP、模型、lint/typecheck/build或实际核对请求。部署只证明服务加载和数据配置保留，不能证明该诊断已经运行通过。完整PRD和AC20/22/13保持未闭环。
