# 发布版本历史与只读快照计划

固定Sim公开execute不能按调用方指定部署版本执行子流程；不添加假pin字段或新调度器。本轮补核心版本基础能力：在原项目流程所有权和编辑授权下分页读取官方发布版本，按明确revision读取历史状态并由原decode/compile校验，返回只读authoring快照和原graph_hash。历史是否活动只代表读取当时，不授予执行或发布权限。

编辑器默认折叠历史列表，用户显式读取；选项只读取版本、展示节点/连线与本页草稿的只读比较及脱敏JSON，不覆盖草稿、恢复、发布或启动。切项目/流程/身份丢弃迟到响应，无自动轮询。原始JSON仍需编辑权限，不进入匿名首页。

不改上游、数据库、角色或原生记忆，不增加依赖。只源码/AST/Luna审查；无测试、Node、HTTP、浏览器或模型探针。后端沿既有授权与优雅维护流程加载。完整固定子流程/递归/总预算仍待实现和验收，不能据快照读取宣称AC33通过。
