# 原运行用量汇总计划

目标：复用已入任务证据的明确Codex响应记录，在已有运行查询中汇总该project/workflow/run的可得计数，覆盖不同节点、循环和重试。保持完整任务/父角色/模型调用次数/费用未知，不将部分统计作为硬预算执行证明。

实现范围：usage.py复用单任务校验，TaskStore同一只读SQLite事务按准确作用域选取任务，既有WorkflowGateway运行GET追加投影，现有中文运行结果显示可测/缺失数量。无新增表、服务、依赖、自动采集或模型调用。

边界：未知/缺失统计不填零；没有可测记录时token合计为null。跨任务重复Codex执行身份、坏JSON、计数超安全整数或来源矛盾使整组未知，不重复累计。仅原run，不把native恢复子run/递归子流程误计入同一运行；UI须说明范围。若某任务包含无效的用量证据，不能悄悄将其当普通缺失继续展示合计。
