# 原生召回证据核对计划

复用原本地父角色快照和任务详情，允许用户输入一段非敏感的预期文本，检查成功memory_search结果中是否出现该文本，以及在此前已成功召回的关联下，当前原生任务委派指令是否也出现同一文本。只返回计数、身份和指纹，不返回查询、结果、指令或记忆正文，不再次召回或执行模型。

原运行Bearer与项目范围、任务版本和已展示快照SHA256必须一致。新只读POST使用已有受控适配服务，不持久化用户文本，不新增数据库、模型服务或检索引擎。缺失快照和未匹配明确显示未知/本快照未观察，不当作检索失败或全历史缺失。

字面文本命中仅是可复查的诊断，不能冒充语义相关性、Recall@K/MRR、自动召回全路径、实际Codex输入注入或真实业务成功。完整PRD的检索效果评估仍需实际样本与人工相关性判断；本轮不运行测试、Node、HTTP、浏览器、模型、lint/typecheck/build，只源码、AST及指定Luna静态复核。
